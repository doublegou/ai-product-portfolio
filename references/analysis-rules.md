## 事实分层

对每条候选热点区分：

1. `publishedAt`：来源提供的发布时间；可能为空。
2. `rank` / `heat`：当前榜单位置或热度文字，只能在同一来源内解释。
3. `fetchedAt`：本次采集时间，不是事件时间。

缺少发布时间时写“截至抓取时当前在榜”，不要写“最近 24 小时发生”。

## 事件归并

- 标题近似只是候选信号；核对实体、动作、版本、日期是否一致。
- 同一文章被多个聚合源转载，属于多来源出现，但不一定代表独立信号。
- 至少两个不同平台指向同一事件，才标为“跨平台共振”。
- 保留每个平台的原始链接；优先把一手来源作为主链接。

## 评分

如需排序，分别给出 0–5 分并说明关键依据：

| 维度 | 判断 |
|---|---|
| 共振 | 不同平台/社区是否同时出现 |
| 时效 | 有证据的发布时间是否新近 |
| 动量 | 榜单名次、点赞、Star 或讨论是否强 |
| 相关 | 是否匹配用户的行业、受众和目标 |
| 创作 | 是否有清晰冲突、利益点、案例或可操作结论 |
| 可信 | 是否有一手来源或多个独立来源印证 |

总分不是事实。不要把不同平台不可比的热度数字直接相加；用户相关性应由请求上下文决定。

## 输出模板

推荐用以下顺序：

1. 三到五条趋势结论，每条附来源。
2. 跨平台共振事件，说明哪些平台重复出现。
3. 高价值但单源的早期信号。
4. 面向目标渠道的选题：标题角度、受众、核心论点、证据链接、风险点。
5. 数据边界：失败来源、无发布时间条目、抓取时间。
