# 已认可制作标准

## 内容与录屏

- 口播是时间线：页面与分步顺序都沿原稿推进，提炼文字可以，重排讲述不可以。先讲的内容不能藏在后面，阶段总结不能为了“收尾”移到最后。
- 干净画面：去掉章节代码、常驻页码、品牌角标与制作说明。来源放元数据或按需面板；必要的示例提示融入内容，例如“示例结果”，不能伪装真实运行。
- 手动点击画面逐步推进，显示完本页再翻页；普通窗口、全屏、隐藏控制栏时均有效。按钮、选页和控制栏热区不透传点击。
- 一套一个自包含编号 HTML，字体与图形内嵌；不保存口播稿或每次制作的额外产物。

## 当前 Jev 系列的认可样板

用户认可 `ppt/001.html` 的口播版：深炭灰 `#181e22`、柔白 `#f0ede6`、薄荷绿 `#a7d9c3`、暖橙 `#e7ab82`；中文 LXGW WenKai TC、英文 Kalam，实际内嵌所需字形；简洁线稿、大留白、少量下划线与按口播揭示。

延续此系列时沿用以上语言。其他主题可以选择其他风格；这不是把所有演示锁成手写黑板。制作新内容时重新为字体子集纳入所需字符，不直接复用旧 HTML 的字符子集。

## 液态玻璃控制栏

- 系统字体用于工具条，正文保持演示本身的字体。
- 使用 `assets/liquid-controls.html`、`.css` 和 `.js`；脚手架自动内嵌，零运行依赖。页码/步数和页选择只在控制栏内出现。
- 通透中性色镜片、背景模糊、轻饱和、弧形反光、细亮边与柔阴影。鼠标位置可影响高光，但不扭曲按钮与文字，不加入持续漂浮或自动闪烁。
- 这是网页实现的液态玻璃视觉，不声称调用 macOS 原生组件或物理折射 API。浏览器不支持背景模糊时使用可读的半透明深色回退。
- 底部中央固定热区；透明时按钮不可点击，进入热区后按钮可用。鼠标停留时保持显示，离开后约 160ms 淡出；不是等待数秒后超时隐藏。
- 点按钮后移开仍要隐藏。键盘 Tab 导航时控件和焦点环必须可见；离开键盘导航回到鼠标时恢复悬停逻辑。触屏保留轻触推进、滑动回退/推进。
- 尊重减少动态效果偏好，关闭移动高光和过渡。窄屏不换行、不出屏，图标保留可访问名称与操作提示。

## 验收

检查正常和全屏下的显现、停留、移出；分别点击下一步、重播、选页，确认每个手势只产生一次正确操作。点击热区空白不能翻页。键盘和窄屏检查独立进行；截图审查高光不能盖住文字。

修改控制栏时对比所有 `.slide` 内容，确保未改写认可的画面和口播顺序。共用模板另用简短合成内容在临时目录生成并实际打开，不能只改现有成品而遗漏后续生成路径。

## 项目与安装副本

本工作区技能源码保存在 `ppt/script-to-html-slides/`，Codex 发现用的安装副本是 `~/.codex/skills/script-to-html-slides/`。维护时先检查两处差异，在同一次更新中同步源码和安装副本，不覆盖未知修改；不复制 `__pycache__`、临时预览或本次脚本。资源使用相对路径，完整目录可独立复制；最终编号 HTML 不依赖技能目录。
