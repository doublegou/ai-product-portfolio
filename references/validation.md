## 2026-09-23：多风格与质量约束改版

已将黑板改为可选参考，新增设计决策、可内嵌的舞台/播放器、脚手架、静态检查器和只读布局审查器。方法参考见 [验收方法](acceptance.md) 的来源部分；实现为本次编写，没有安装或运行远端 skill 代码。

### 可重复的工具测试（本轮 15 项均通过）

```bash
python3 <技能目录>/scripts/test_tools.py
node --test <技能目录>/scripts/test_state.cjs
node --test <技能目录>/scripts/test_audit.cjs
```

- 静态工具：6 项，包含成品骨架内嵌、占位拒绝、外部/相邻资源检测、data URI 与 SVG 片段、错误分步/重复 ID、拒绝覆盖已有文件。
- 播放状态：6 项，包含逐步揭示后翻页、跨页回退、首尾边界与快速连续输入、直接翻页/重播、初始参数限制、避免调用方篡改状态。
- 布局审查：3 项，使用**合成矩形和最小 DOM 替身**，检查正常分离内容、越界/重叠/裁切检测、忽略隐藏元素及有意叠放。它们测试审查逻辑，不能验证真实浏览器字体、布局或绘制。

### 限制

三种不同布局方向的内部测试 HTML 已在临时目录生成并通过静态预检。尝试打开本地测试页时，浏览器 URL 安全策略拒绝 `file://`，因此没有绕过限制继续渲染，也没有完成真实浏览器逐页截图、字体、缩放、键盘绑定、触摸、全屏或实际动画检查。这些仍需在允许的实际制作环境验证。

内部测试页面使用系统字体回退，未进行字体封装或审美校准，不是认可模板，不作为用户作品交付。`ppt/` 未新增文件。没有运行独立模型生成对比，也没有测得跨脚本设计稳定性或用户满意率。

后续若发生真实缺陷，先复现再补充对应回归测试。只有用户明确认可时才记录某个系列的视觉基准，不能从工具测试成功推出设计已获认可。
