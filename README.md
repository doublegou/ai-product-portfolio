# 李适的 AI 产品作品集

本仓库集中整理三个项目组的代码、产品案例、演示与验证材料。目前为私有建设版本。

| 项目组 | 关注的问题 | 入口 |
| --- | --- | --- |
| 内容生产 Agent 与 Skill 工具链 | 如何把内容任务拆解为可复用、可验收的工具与流程 | [查看项目](projects/01-content-agent/README.md) |
| StayWord 端侧语音产品 | 如何在设备与模型约束下交付完整的录音、转写和摘要体验 | [查看项目](projects/02-stayword/README.md) |
| RiverSR 建模与科研应用 | 如何验证泛化能力、诊断失败并定义模型适用边界 | [查看项目](projects/03-riversr/README.md) |

各项目组的 `src/` 保留来源仓库的独立工程结构；`docs/` 存放设计与过程材料，`demo/` 存放演示，`evaluation/` 存放验证方法与结果。现有实现、事后复盘和后续计划分别标注，尚未完成的验证不作为成果。

九章的私有资产不纳入本仓库。源码保留各自的作者与许可证信息，本仓库不统一重授第三方内容许可。

来源版本和导入说明见 [SOURCES.md](SOURCES.md)。
