## 材料状态

“代码可见”表示导入版本中存在相应实现，不等于本次完成运行验收；“过程记录”表示来自历史笔记，数字仍需与原实验输出逐项核对；“待验证”与“设计提案”不作为已取得的成果。

各案例涉及的个人职责由本人后续校正；不根据代码提交数量推断团队分工。本次不导入九章的公司资产，也不将本仓库作为简历的重复副本。

## 仓库边界

这是独立私有副本。后续修改在本仓库进行，不回推原项目；原本地项目的 Git 配置与原仓库不作修改。来源历史中的作者、许可和说明均保留，本仓库未对第三方源码、模型或素材统一重新授权。公开前再逐项确定材料范围。

模型与原生依赖使用 Git LFS，首次克隆需要 Git LFS。项目运行要求分别见原工程 README；不提供会同时启动多个工程、联网或发布内容的总启动脚本。
