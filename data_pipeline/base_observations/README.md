# data pipeline base observations

## Purpose

Build the base river-Sr observation dataset from shared raw observations and environmental sources.

## Entry

```powershell
Rscript data_pipeline/base_observations/run.R
```

## Data boundary

- Input: `data/raw/observation.csv`
- Output: `data/processed/base_observations/observations.csv`
