# data pipeline supplement observations

Build the supplemented global observation dataset from shared raw sources.

## Entry

```powershell
Rscript data_pipeline/supplement_observations/run.R
```

## Data boundary

- Input: `data/raw/observation.csv`
- Output: `data/processed/supplement_observations/observations.csv`
