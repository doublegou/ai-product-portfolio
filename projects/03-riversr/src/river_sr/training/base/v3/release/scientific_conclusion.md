# Base V3 scientific conclusion

Run: `base_v3_full_20260817_r2`

在5,600个站点、50个冻结预测变量和严格水文系统隔离的 Nested CV 下，Random Forest 的 pooled Outer-OOF RMSE 为0.017235，低于XGBoost的0.017723。RF在三次Outer重复中全部优于XGBoost，并赢得15个配对Outer task中的13个；500、1,000和1,500 km三种空间Stress的pooled RMSE也均为RF更低。因此接受RF作为Base V3全球连续Sr回归模型。

站点级OOF结果由每个站点的三次严格Outer预测取均值得到。RF的RMSE为0.017197、MAE为0.006263、低值RMSE为0.005554；在708个`0.72–0.75`站点中命中317个，在107个`0.75–0.80`站点中命中4个，在29个`Sr >= 0.80`站点中命中0个。XGBoost对应命中数为218、3和0。两种模型对5个极高值水系的命中数均为0。

RF能够输出0.80以上的严格OOF预测，但该预测对应的真实Sr仅为0.7543。XGBoost的0.80以上pooled预测也全部落在真实值不超过0.7543的站点。与此同时，最终全数据RF在训练集上能够命中29/29个`Sr >= 0.80`站点，而严格OOF为0/29。这说明限制来自高值信号无法迁移到未见水系，而不是模型输出范围或训练拟合能力不足。

最终RF配方为`rf_110 / W2`：mtry 12、min node size 1、无放回抽样、sample fraction 0.8和4,000棵树。W2在15个RF Outer task中被选择10次，具有重复验证支持；但它没有解决极高值泛化。

结论：冻结并发布`base_v3_full_20260817_r2`的RF模型，发布范围为全球连续Sr回归。该模型不得被解释为高-Sr水系发现、极高值分类或风险筛查模型；这些用途未通过科学验收。
