# RiverSR · 全球河水锶同位素预测研究

**实验室与中科院合作背景下的科研项目：从多来源环境数据出发，研究 AI 能否预测未采样河流，以及这种预测能够迁移到哪里。**

我独立完成项目中的数据整理、环境特征构建、模型实验、验证工程与地图应用探索。研究从全球连续预测基线出发，逐步检验高值识别、残差修正、新支流泛化与区域专家模型，最终形成 **5,600 站点的数据版本、按真实使用条件划分的验证体系，以及带适用边界的模型配方**。下一阶段转向稳定预测信息的发现与迁移验证。

这个项目的核心判断是：**先定义模型要进入什么样的陌生环境，再决定用什么数据、模型和证据评价它。**

## 研究要解决什么问题

河水的 **⁸⁷Sr/⁸⁶Sr** 是锶同位素比值。本项目以站点观测为目标，将地质、水文、气候、土壤和河网信息作为预测输入，希望为未采样地点提供连续估计，并为进一步研究与采样提供参考。

难点在于，河流沿上下游连接，站点并不是彼此独立的样本；不同资料来源、地理区域和稀少高值又存在分布差异。一个在已有站点附近表现不错的模型，未必能够进入完整陌生水系。因此，我把研究任务拆成三个层次：

| 研究任务 | 需要回答的问题 | 研究中的处理 |
| --- | --- | --- |
| 连续预测 | 环境变量能否估计未采样站点的同位素比值？ | 构建 Full50 基线，比较 RF 与 XGBoost，报告误差、偏差与解释能力 |
| 跨域泛化 | 新支流、完整陌生水系、新空间区域是否需要不同承诺？ | 分别设计下游剔除的支流验证、完整水系隔离、空间及来源压力测试 |
| 信息与机制 | 高值漏检来自模型容量，还是输入没有表达关键差异？ | 用分类、修正、区域过程特征与失败诊断逐步检验；据此设计下一阶段信息贡献研究 |

当前交付是**研究工作流与模型成果**。地图用于探索查询方式；真实预测服务和来源推断仍是后续应用方向。

## 已完成的核心成果

### 1. 将分散观测整理为可持续迭代的数据资产

我把基础 **4,485 站点**与九个公开来源的补充观测整合为 **5,600 站点、50 个冻结预测变量**的数据版本，保留来源、站点身份、河网匹配和质量控制记录。数据覆盖 364 个完整水文系统；这里的水系数与站点数分别用于判断独立环境支持与样本规模。

扩充过程中，先排除可能与旧版本重复的记录，再聚合坐标、匹配河网、构建局地及上游特征。旧站点的身份和响应保持一致，让后续实验可以区分“数据版本发生了什么变化”。[数据构建与质量控制](docs/technical-design.md#数据如何形成)

### 2. 把“预测得准”落实到具体使用场景

我为**已有观测水系中的新支流**设计了 Downstream-Purged Branch CV：完整留出待测支流，同时从训练集中剔除其下游站点，避免利用沿河网传播的信息。Base V2 在 **221 个支流、2,577 个适用站点**上得到站点均值 OOF **RMSE 0.01334、R² 0.425**。

为检验结果是否依赖某一种划分，我比较了三个支流尺度下的九套设计。在匹配测试条件的基准实验中，Purged Branch 在四项预设指标上均有 **9/9 套设计优于 Matched Terminal**。这支持区分“新支流”和“完整陌生水系”，而不是给所有预测场景同一个精度承诺。[支流实验结果](src/river_sr/training/base/v2/RESULTS.md)

### 3. 用同口径实验选择全球模型

Base V3 面向**完整陌生水系**，使用 3 次重复 × 5 折外层验证，并在每个外层训练集内完成 5 折调参。RF 与 XGBoost 使用相同分组及候选结构搜索预算；权重和参数只在内层选择。

| Base V3 严格水系隔离验证 | Random Forest | XGBoost |
| --- | ---: | ---: |
| Pooled OOF RMSE ↓ | **0.017235** | 0.017723 |
| Pooled OOF MAE ↓ | **0.006295** | 0.006554 |
| Pooled OOF R² ↑ | 0.0800 | 0.0271 |

RF 的 RMSE 相对降低 **2.76%**、MAE 相对降低 **3.95%**，在 3/3 次重复和 13/15 个配对外层任务中取得更低 RMSE，因此选择 RF 作为全球连续预测研究基线。完整陌生水系上的解释能力仍然有限。

这里的 pooled 指 5,600 站点各自三次外层留出预测的合并评价，不代表 16,800 个独立样本。Base V2 与 V3 的测试人群、任务和汇总口径不同，不能将两者分数作为模型升级前后的直接比较。[模型竞争与压力测试](src/river_sr/training/base/v3/RESULTS.md)

### 4. 通过失败实验判断下一步该投入什么

![正式运行中的模型比较、训练拟合与极高值外推差异](demo/assets/model-evidence.png)

左图回答“同一任务下选哪个算法”；右图回答“训练表现能否迁移”。RF 能在训练拟合中命中全部 29 个极高值站点，但严格站点均值 OOF 命中为 **0/29**，极高值水系为 **0/5**。这使我把连续估计与高值发现分开验收。

我进一步比较了非坐标高值分类、二层残差修正、区域 GAM、RF / XGBoost，以及 14 个水文—地质过程衍生特征。几个关键结果改变了研究路线：

- **学到残差不等于改善最终预测。** Full50 残差 RF 相对残差对照改善 21.76%，相对未修正基线却退步 0.95%，因此保留原模型。
- **整体排序不等于覆盖陌生水系。** 区域 RF 在控制误报后仍只识别 6/14 个阳性支流；新增 Process14 没有改善跨支流表现。
- **换模型之前先查输入。** 完全漏检的 28 个高值站点，其 64 个特征落入普通背景区间的比例中位数为 95.3%。结合跨支流近邻诊断，这支持优先调查信息缺口，而不是继续在相同特征上调参。

这些结果没有证明高值不可预测；它们帮助我收敛当前路线，并把下一阶段的重点转向**新信息的独立贡献、稳定性与适用条件**。[实验设计与决策依据](docs/case-study.md)

## 从研究到应用：交付给使用者什么

| 使用环节 | 已有交付 | 解决的问题 |
| --- | --- | --- |
| 准备与更新数据 | 观测版本、Full50 定义、河网分组、构建 manifest | 新增数据如何进入实验，变化能否追溯 |
| 运行与比较模型 | R 管线、嵌套验证、Slurm 任务、冻结配方 | 能否在相同条件下复用方法和比较候选 |
| 解读结果 | 连续误差、支流/水系覆盖、尾部诊断、使用范围 | 哪些结论有证据，哪些场景需要继续研究 |
| 探索查询 | 已有地图交互原型 | 用户如何输入同位素条件并查看空间结果 |

当前冻结 RF 配方与结果摘要可直接查看；模型二进制未随作品集附带。地图使用合成场，尚未与真实回归模型连接。下一步接入需要完成特征提取、不确定性、输入域检查和查询结果绑定，才能把界面转成可信的研究工具。[实际交付物与原型截图](demo/README.md)

## 下一阶段：找出可迁移的预测信息

Direction 2 已形成研究方案：从地质、水文、河网混合、气候地表、人类活动和空间位置六类候选信息出发，先比较信息模块，再嵌套筛选稳定变量；用独立水系确认集检验精简特征集是否足够，最后测试空间、环境域与来源迁移。

若统一模型在某一环境域失败，先诊断并重新寻找更稳健的全球特征集；只有新信息仍不足、且证据支持关系存在差异时，才投入域专属模型。**这一部分是下一阶段方案，尚无完成结果。** [阶段目标、实验门槛与交付规划](docs/decision-timeline.md#下一阶段direction-2)
