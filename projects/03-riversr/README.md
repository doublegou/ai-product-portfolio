# RiverSR

**为陌生水系预测河水锶同位素组成，并用严格验证限定模型能承担的任务。**

我独立完成 RiverSR 的数据整理、特征构建、模型实验与应用探索，将多来源观测转成可在陌生水系中验证的预测工作流。最终选择 Random Forest 作为连续预测研究基线，并根据尾部失效结果收窄用途；地图原型用于探索研究结果的使用方式。

[产品与研究决策](docs/case-study.md) · [技术与验证架构](docs/technical-design.md) · [结果复核](evaluation/README.md) · [Quick start](docs/quick-start.md) · [实验演进](docs/decision-timeline.md)

## 要解决的决策问题

河水的 **⁸⁷Sr/⁸⁶Sr** 是无量纲同位素比值，可以提供地质来源与水体混合的信息。采样覆盖有限，研究者希望根据环境信息估计未观测地点的比值，并判断哪些区域值得进一步调查。

这里必须分开两个任务：**预测连续数值**与**发现高值水系**。平均误差较低，不代表模型找得到稀少的极高值。研究者需要知道的是“这个估计在怎样的陌生水系里仍可信”，而不仅是得到一张颜色丰富的地图。

| 实际工作环节 | 本项目交付 | 使用边界 |
| --- | --- | --- |
| 汇集河水观测并构造特征 | 5,600 个站点、冻结的 Full50 特征定义和来源记录 | 多来源采样与极端值稀疏会影响外推 |
| 选择能进入陌生水系的模型 | 水系隔离 Nested CV、RF / XGBoost 同口径比较 | 不能用训练拟合分数代替泛化表现 |
| 决定结果可用于什么 | 连续回归 RF 配方、压力测试、尾部诊断与用途限制 | 不批准高值发现、极高值分类或风险筛查 |
| 探索地图交互 | 地图原型与查询流程 | 当前使用合成场，尚未连接真实模型 |

## 最关键的结果：RF 更好，但还不能筛查极高值

![RF 与 XGBoost 的严格验证、训练拟合与尾部结果](demo/assets/model-evidence.png)

图中数据来自正式运行 `base_v3_full_20260817_r2`。左图为严格 Outer-OOF pooled RMSE：5,600 站点 × 3 次重复，共 16,800 条预测；右图将训练拟合与严格站点均值 OOF 的极高值命中分开，分母均为 29 个站点。两种验证的差距就是用途限制的依据。

| 同口径比较 | Random Forest | XGBoost | 对决策的意义 |
| --- | ---: | ---: | --- |
| Primary pooled OOF RMSE ↓ | 0.017235 | 0.017723 | RF 相对降低 **2.76%**；3/3 次重复均较低 |
| Primary pooled OOF MAE ↓ | 0.006295 | 0.006554 | RF 相对降低 **3.95%** |
| Primary pooled OOF R² ↑ | 0.0800 | 0.0271 | 整体解释能力仍有限，适用范围保持为研究基线 |
| 站点均值 OOF：Sr ≥ 0.80 命中 | **0 / 29** | **0 / 29** | 极端尾部外推失败 |
| 站点均值 OOF：极高值水系命中 | **0 / 5** | **0 / 5** | 漏检不是单个异常站点的问题 |
| 全数据训练拟合：Sr ≥ 0.80 命中 | 29 / 29 | 28 / 29 | 模型能拟合高值，不代表能迁移 |

**我的选择是保留 RF 作为连续回归研究基线，限制高值相关用途。** 选型以预先定义的水系隔离验证为准，训练拟合和压力测试用于解释结果。

这里展示正式冻结运行结果；数据分布与摘要指标可通过[复核脚本](evaluation/README.md)检查，无需重跑 HPC 训练。

## 端到端工作流

![RiverSR 从输入、隔离验证到用途决策的架构](demo/assets/architecture.svg)

我将**输入 → 数据冻结 → 模型竞争 → 外推验证 → 使用决策**组织为一条研究流程。地图是后续应用探索，图中虚线表示尚未接入真实模型的接口。

### 1. 把“更多数据”变成可审计的数据版本

基础 4,485 站点增加 1,115 站点，形成 5,600 站点版本；冻结站点身份、50 个预测变量和水系分组。Sr ≥ 0.80 只有 29 站点，占约 0.52%。因此总 RMSE 与尾部命中必须同时报告，单一平均指标可能掩盖最需要关注的失败。

### 2. 用实际使用条件定义验证

同一水系中的观测共享背景，随机拆分容易高估陌生水系表现。Base V3 在外层和内层都隔离完整水系：外层 3 次重复 × 5 折；每个外层训练集再做 5 折内层选择。预处理、权重与参数在训练分区内确定，冻结后才使用外层测试。

### 3. 用最终增益决定是否采用修正模型

此前二层高值修正的四个候选都学到了残差信号，但相对未修正 Raw Base 的平均改进均为负。最接近的 Full50 残差 RF 相对残差对照改善 21.76%，相对 Raw Base 却为 **−0.95%**，最终不发布。对照选错会让一次退步看起来像成功。[最终修正实验](src/river_sr/training/global_correction/high_sr_correction_feasibility/RESULTS.md)

### 4. 将研究结果与地图原型分别交付

地图工程探索“输入同位素条件—运行查询—查看空间结果”的使用方式。当前域计算使用合成同位素场，渲染颜色还使用独立的展示函数，未直接读取查询分值。它可说明界面与计算模块组织，不能用作真实来源概率、模型推理结果或精度证据。[实际原型与接入缺口](demo/README.md)

## 为什么下一步不是继续换一个更复杂的算法

RF 与 XGBoost 都能拟合训练极端值，却都无法识别隔离水系中的极高值；增加算法复杂度并没有解决现有信息对迁移的不足。下一步研究方案 **Direction 2** 转向信息贡献与迁移边界：扩展地质、水文、河网混合等候选特征，在嵌套验证中筛选稳定信息，并用独立水系确认集检验精简特征是否足够。这是已设计的后续方案，不是已完成结果。

下一步我先完善输入域、模型版本和不确定性接口，再将连续预测接入地图；高值筛查继续保持未通过状态。
