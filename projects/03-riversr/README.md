# RiverSR · 全球河水锶同位素预测与应用研究

**为未采样河流建立锶同位素预测基线，并判断它在什么条件下能够支持后续研究。**

这是实验室与中科院合作背景下的科研项目。我独立完成这里展示的数据整理、特征工程、模型训练、验证与运行工程，并推进生物来源研究的应用设计。

研究者希望利用河水的 **⁸⁷Sr/⁸⁶Sr（锶同位素比值）**，理解地理环境差异，并探索水生生物的来源。但实测站点有限；从已有地点预测新河流，还会遇到水系、环境和资料来源变化。项目需要同时回答：**哪里可以估计、哪些结果需要谨慎使用、还缺什么证据才能进入应用。**

## 从研究问题到可交付成果

我先建立“观测整理 → 环境输入 → 基线模型 → 留出验证”的最小闭环，再根据误差和对照实验扩展信息，最后进入独立应用验证。

| 交付 | 已形成的成果 | 支持的研究决策 |
| --- | --- | --- |
| 可重复的预测基线 | 5,600 站点的数据主线、特征版本、训练与验证管线；后续推进至 Natural90 自然环境基线 | 用统一输入与评估条件比较方案，明确结果适用的预测场景 |
| 模型与信息的采用依据 | 支流/水系隔离验证、共同失败诊断、Human17 配对增量检验 | 区分可以保留的能力、需要补充的信息和应停止的复杂方案 |

目前交付到**科研预测与可靠性研究、应用基准准备**。生物来源推断和迁移重建尚未完成独立验证。

## 三个改变方案的关键判断

### 1. 先定义“预测哪个新地点”，再决定怎样评价模型

在已有观测的大水系中预测一条新支流，与预测完整陌生水系，所需能力不同。简单留出支流还可能保留下游观测，让验证过于乐观。

我设计不依赖同位素响应的支流划分，并在训练和选参时剔除待测支流的下游站点。九套设计的四项预设指标均优于匹配的完整水系对照，说明两种场景应分别评价。因此，我保留**新支流预测**的独立适用范围，也保留**陌生水系迁移**的严格检验。研究者得到的精度说明必须对应自己的任务。[验证设计与结果](src/river_sr/training/base/v2/RESULTS.md)

### 2. 模型平均表现更好，还要确认它能否完成具体任务

早期完整水系验证中，RF 的 RMSE 比 XGBoost 低 **2.76%**，我据此选择该阶段的连续预测基线。但 RF 训练拟合命中了全部 29 个极高值站点，严格留出预测却是 **0/29**：它仍不能承担可靠的极高值发现任务。

残差修正、区域模型与过程特征的实验也没有通过各自采用标准。我停止继续叠加这些模块，将投入转向输入信息和失败环境。原始逐站预测进一步表明：实测值 ≥0.75 的 136 个站点占样本 **2.43%**，却贡献 **82.90%** 的平方误差，说明平均指标掩盖了集中失效。后续 Natural90 研究发现 **74 个站点在五种迁移方案中均出现三算法共同失败**，进一步将问题聚焦到跨算法仍难解决的环境。交付因此增加了可靠性诊断，帮助确定后续补充信息的重点。[逐站误差诊断与示例](demo/README.md#从逐站结果定位信息缺口) · [假设与实验演进](docs/decision-timeline.md)

### 3. 新信息必须证明增量价值，才能进入正式预测层

人口、土地利用、污水、采矿和坝库信息具有领域意义，但维护这些输入和新增全球预测层也会带来成本。我在**同一批 5,517 站点、同一测试划分**上，比较自然环境基线与加入 Human17 后的表现，避免把样本变化当成模型进步。

发现坝库特征未执行冻结的时间规则后，我修复输入并重新分析。三种算法均未通过整体增量标准，只有一个算法与迁移条件组合获得实质改善。因此继续保留 Natural90 主基线，保留 Human17 的研究结论，暂不增加正式人类活动预测层。这一决定针对当前全球代理变量的预测收益，不作因果结论。[完整配对结果](evaluation/later-research-records.md#3-human17修复时间口径后重跑配对实验)

## 让研究判断能够落实到训练与交付

实现上，我用训练分区内预处理、嵌套验证和冻结测试划分控制信息泄漏；用相同搜索预算比较算法；用 CPU / Slurm 编排、内层早停和候选检查点控制计算投入。后续重分析中，55 个任务在输出阶段失败，只恢复对应索引，保留有效计算。

交付包含数据版本、特征定义、冻结 RF 模型、XGBoost 对照快照、原始留出预测与使用条件。模型通过 Git LFS 保存，输入、模型和结果可按版本与哈希对应。资源申请、已测耗时与费用口径分开呈现；完整训练设计、已保留日志和成本口径放在[技术方案](docs/technical-design.md#训练资源耗时与成本)中。

## 下一步：用独立应用验证决定是否继续扩展

下一阶段的关键问题是：**河水预测能否帮助解释独立生物记录，并缩小来源候选范围？** 我将验证拆为预测水与实测水、实测水与生物记录、已知来源覆盖三个环节，以便定位应用失败发生在哪里。

目前已整理并冻结生物基准；严格集合仍集中于少数来源，因此优先补充独立性并完成预测对照。通过后再推进具体迁移案例。[研究需求、交付标准与应用规划](docs/case-study.md)
