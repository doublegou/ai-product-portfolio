## 每条结果需要的定位信息

实验阶段、数据版本、样本数、特征集合、模型配置、训练/验证分组、指标聚合方式、结果文件、来源提交、通过标准与最终决策。

claims-template.csv 用于逐条登记。先核对案例中采用的关键数字，不要求为作品集重跑全部实验。

## 必须分开的比较

- 新支流与完整陌生水系属于不同外推问题。
- pooled OOF、站点均值 OOF 与训练集拟合不是同一指标口径。
- 排序质量、校准质量和固定误报约束下的识别能力分别评价。
- BasePred-only correction 对照与未修改 Raw Base 对照不能混用。
- Direction 2 的实验设计与方向一已完成结果分开展示。
