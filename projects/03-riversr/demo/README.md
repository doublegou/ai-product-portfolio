# RiverSR 演示准备

状态：待制作，本轮未生成新的实验图或预测结果。

建议先做一次五分钟案例演示：

1. 用户/研究任务与模型预期用途。
2. 说明为什么陌生水系需要独立验证。
3. 对照一个关键实验，解释局部指标改善为何仍不足以通过。
4. 展示失败审计如何改变路线。
5. 说明最终交付范围和 Direction 2 计划。

优先从允许展示的现有结果制作一张验证设计图、一张同口径比较图和一张决策时间线。原笔记见 docs/research-notes/，不要直接把整份笔记作为演示正文。

地图可作为独立交互原型展示，明确标注合成场与尚未接通真实预测，不能把背景热力图作为科研结果。完整训练和实际数据加载不在本轮执行范围。
