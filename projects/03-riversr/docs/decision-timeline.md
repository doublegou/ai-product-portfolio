## 优先核对的四条数字

1. Base V3 从 4,485 到 5,600 站点的数据构成和清洗口径。
2. RF 与 XGBoost 的 pooled OOF RMSE：0.017235 与 0.017723；比较必须保持同一实验设计。
3. 严格站点均值 OOF 中，两个模型均漏掉全部 29 个 Sr ≥ 0.80 站点及 5 个极高值水系。
4. Correction 在对应残差对照上改善，却未改善 Raw Base；需要同时展示两类对照。

这些数值不是本轮新增测量。笔记中 Base V2 的 branch/station 数与较早简历版本不同，应先对应确切版本再统一公开文案。
