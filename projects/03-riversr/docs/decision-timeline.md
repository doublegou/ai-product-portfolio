# RiverSR：假设、实验与研究投入的演进

[返回项目](../README.md) · [研究判断与应用设计](case-study.md) · [训练与资源](technical-design.md)

我按“发现什么问题 → 提出什么解释 → 用什么实验区分 → 怎样改变投入”复盘项目。早期笔记、最终运行记录与后续执行回报共同构成这条主线；阶段描述是对已有工作的整理，不将事后解释写成当时已经留档的立项文件。

## 第一阶段：建立可以信任的最小研究闭环

**问题与假设。** 多来源河水观测能否与全球环境信息连接，形成对未采样地点有参考价值的连续预测？先验证完整流程，再决定是否值得扩展模型与应用。

**实验。** 整理 4,485 个 Full50 站点，以 RF 建立早期基线。Base V0 的主要场景是空间隔离，Base V1 升级到重复嵌套水文分组；预处理和选参在训练分区内完成，外层记录 OOF。

**结果与决策。** 普通背景可以形成基线，但高值随真实 Sr 升高而明显被压缩。将连续预测保留为主线，拆出高值发现与修正两个独立假设，避免为了一个平均指标同时承诺全部用途。

**投入选择。** 优先完成数据、分组和复现契约，让之后每个实验能够共用可追溯输入。早期地图探索保留为应用原型，不以 UI 完成度判断模型是否可用。[早期工程](../src/river_sr/training/base/v1/RESULTS.md)

## 第二阶段：尾部误差能否通过一个小模块补足

**假设 A：** 去掉坐标后，环境变量中仍存在跨水系高值识别信号。

我比较 Elastic Net 与 Probability RF，在冻结的水系分组中选择参数和阈值，同时检查召回、精确率、误报、PR-AUC 及独立水系覆盖。两个候选均未通过资格门槛，未建立生产分类器。

**假设 B：** 即使入口分类困难，现有信息能否在理想 elevated-Sr 条件下修正 Base 的系统性低估？

我先严格 cross-fit Base，再比较 BasePred-only、Env47 + BasePred、Full50 + BasePred 的修正；分别设置“额外残差信号”与“最终预测优于 Raw Base”的判定。Full50 残差 RF 在第一层对照上改善 21.76%，对 Raw Base 却为 −0.95%。

**结果与决策。** 有中间信号，但没有最终收益；四个候选均停止。这避免继续投入高值入口、全量修正训练和地图接入。Oracle 可行性也不能当成上线时已经知道真实 Sr 的流程。[高值实验](../src/river_sr/training/global_correction/global_high_sr_risk/RESULTS.md) · [修正实验](../src/river_sr/training/global_correction/high_sr_correction_feasibility/RESULTS.md)

## 第三阶段：是否把两种使用场景放在了同一个标准下

**问题与假设。** 完整水系留出移走了大量相关背景，是否过于保守地回答了“同一宏观水系中的新支流”问题？反过来，简单支流留出又可能保留带有信息的下游站点。

**实验。** 在相同条件下比较 Naive Branch、Downstream-Purged Branch、Matched Terminal；用三个尺度、九套设计检验划分敏感性。branch 边界不使用 Sr，外层和内层都执行下游剔除。

**结果与决策。** Purged Branch 在四项预设指标上均 9/9 优于 Matched Terminal，但不稳定优于 Naive Branch。保留 purge 并建立独立的新支流适用范围；不为了较低分数放宽隔离，也不将支流成绩转移给陌生完整水系。

**投入选择。** 先用固定配方做验证几何对照，再进入正式嵌套训练。Base V2 方法基准为 135 次拟合，完整正式流程记录 5,081 次 RF 拟合；前者回答“怎么评”，后者回答该条件下“怎么训练”。[Base V2](../src/river_sr/training/base/v2/RESULTS.md)

## 第四阶段：区域化、更强模型与过程表示能否解决漏检

**问题与假设。** 高值集中在少数区域。缩小到喜马拉雅之后，可能存在全球模型未能捕捉的区域规律；排序信号也可能需要校准才能用于实际筛查。

我分三步扩大投入：

| 实验层次 | 新增假设与最小实验 | 计算规模 | 下一步决策 |
| --- | --- | --- | --- |
| Regional V1 | 空间/环境 GAM 与低复杂度 Elastic Net，检验跨支流信号 | 85 次模型拟合 | GAM 有信号，进入校准与门槛验证 |
| Regional V1.1 | 固定两套 GAM，嵌套 LOBO 生成校准与阈值 | 578 次 GAM 拟合、34 校准器、68 阈值 | 排序尚不足以通过筛查标准，再检验容量和表示 |
| Regional V2 | RF / 浅层 boosting × Full50 / Full50 + Process14 | 68 Outer 任务、1,156 次拟合 | 四候选均不通过；转入冻结失败集合诊断 |

**结果与决策。** Full50 RF 最接近筛查标准，但只覆盖 6/14 个阳性支流；Process14 没有改善跨支流结果。失败诊断中，漏检站点的多数特征仍落在普通背景范围，跨支流近邻也未形成高值富集。

我停止同一批特征上的算法循环，把新投入转向信息来源和表达尺度。这里否定的是已测试组合的可用性，不能推出所有算法或水文—地质机制均无效。[区域实验](../src/river_sr/training/regional_expert/regional_risk_v2/RESULTS.md) · [失败诊断](../src/river_sr/training/regional_expert/regional_failure_audit/results/FAILURE_AUDIT.md) · [任务计时](technical-design.md#从保留日志能测出什么)

## 第五阶段：扩大覆盖后，算法与信息哪个更值得投入

**假设。** 增加全球覆盖并公平比较两种非线性模型，可以检验旧结论是否受数据量或算法容量限制。

**实验。** 数据扩充到 5,600 站点，在严格完整水系隔离下比较 RF / XGBoost。30 个 Primary 外层任务均采用相同的 48→16 结构搜索与三套权重，配置预算为 28,830 次 fit 调用；再做固定配方压力测试。

**结果与决策。** RF 的 pooled RMSE 相对低 2.76%，成为 Base V3 配方。两算法能拟合训练极高值，却都在严格 OOF 漏掉全部 29 个极高值站点。继续保持连续预测研究基线，把研究问题推进为“哪些信息具有独立、可迁移的价值”。[Base V3](../src/river_sr/training/base/v3/RESULTS.md)

## 第六阶段：从信息扩展到 Natural90 可靠性研究

**问题与假设。** 当算法之间的差异不足以解释共同失效时，需要检验更完整环境信息，并寻找不同算法仍然共同困难的环境。

后续执行记录中，自然环境主线已推进至 Natural90，适用人群为 5,543 个站点，比较 RF、XGBoost、LightGBM 及五类迁移方案。三算法共同失败在精确的迁移 context 内定义，再汇总到站点；环境域 K=7 的选择不读取 Sr 或预测误差。

**结果与决策。** 777 个站点在至少一种方案中共同失败，74 个在五套方案中重复出现，HG4/HG6 更困难。研究交付因此包含全球基线与可靠性诊断，而不是只给一张图或一个平均误差。

**投入选择。** 区分站点、context、测试人群和资料来源，先消除指标口径冲突，再讨论机制。对最困难河流系统同时检查多来源和多支流支持，防止把资料来源问题直接解释为环境规律。[后续 Natural90 记录](../evaluation/later-research-records.md#2-natural90-共同失败与环境域)

## 第七阶段：人类活动信息是否值得进入全球预测层

**假设。** 人口、土地利用、污水、采矿和坝库等 Human17 代理信息，在自然基线之外提供稳定增量，足以支持新增预测层。

**实验。** 在 5,517 个相同站点上比较 M2（Natural90）与 M3（Natural90 + Human17），冻结训练/测试身份、算法、候选和 gate。按算法与迁移任务报告误差差值及 bootstrap 区间，整体准入不由单个有利 cell 决定。

**数据错误与恢复。** H13 坝库特征未执行冻结的 2015 cutoff，需要纠正输入而非调整模型。修复只影响规定字段；其他 Human14、Sensitivity7、Natural90 模型及全球图受保护。重新计算人群，完成 210 Outer contexts 与 25,920 candidate-fold checkpoints；输出失败的 55 个任务仅恢复对应索引。

**结果与决策。** LightGBM × 500 km 的局部改善没有在其他迁移条件下形成稳定支持，0/3 算法通过整体标准。因此不构建正式 Natural+Human 全球预测层，保留自然基线与人类活动增量研究结论。Sensitivity7 的数据 QA 完成，但缺少冻结模型协议，未把它补写成已完成模型实验。[修复与配对实验完整记录](../evaluation/later-research-records.md#3-human17修复时间口径后重跑配对实验)

## 第八阶段：地图之外，是否存在可验证的应用价值

**假设。** 全球河水基线可能支持水生生物记录和来源研究，但水预测误差、生物记录差异、真实来源覆盖是三个不同问题。

我将应用设计为两层：先用独立实测水、生物记录和已知来源样本建立基准，再选择连续耳石记录与河网连接相结合的迁移案例。执行回报表明，生物数据已完成标准化、独立性/重复谱系检查与协议冻结，冻结前未访问模型预测。

**当前决策。** 扩展集合覆盖 20 个研究和 14 个流域组，但严格集合集中度高；下一步先完成独立匹配和预测对照，不能用一个演示案例替代跨来源验证。迁移重建仍是待推进应用，不记为已验证效果。[应用数据与限制](../evaluation/later-research-records.md#4-应用验证先建立独立生物数据再评价地图)

## 原始 Direction 2 与后续研究如何对应

原始笔记提出“候选信息库 → 嵌套筛选 Core → 独立确认 → 域泛化 → 失败重发现 → 条件性专家模型”。后续 Natural90 / Human17 已有执行成果，因此它们应进入项目主线。与此同时，Natural90 的完成不能自动证明原方案的精简 Core、lockbox 非劣性确认等环节均已执行。

原方案中仍有价值的研究原则包括：

- **独立增量：** 用 `RMSE(Spatial) − RMSE(Spatial + Block)` 及 `RMSE(Expanded − Block) − RMSE(Expanded)` 区分位置代理与额外信息。
- **稳定筛选：** 训练分区内建立相关变量簇，先簇后变量进行置换和重新建模，以跨折选择频率评价稳定性。
- **独立确认：** 精简方案冻结后再确认；已参与历史决策的站点不能通过重新切分获得“完全外部验证”的身份。
- **预测与解释：** 预测贡献、统计关联和因果机制分别讨论；高重要性不直接解释为因果作用。
- **复杂度门槛：** 失败域先检查覆盖、信息与混杂，统一特征仍不足且有关系差异证据后再增加专家模型。

这些原则用于解释后续实验选择；未取得相应结果的研究分支仍标记为方案。原件：[优化笔记](research-notes/模型优化记录final.docx) · [Direction 2](research-notes/direction2.txt)。

## 下一笔投入的优先级

| 优先级 | 下一步 | 为什么先做 | 完成后可以推进什么 |
| --- | --- | --- | --- |
| P0 · 成果交付 | 将后续冻结 registry、模型配方、关键结果表和运行账单与作品集对应 | 让成果可以由文件复核，而不只依赖执行回报 | 补齐真实结果图、模型版本和实际资源成本 |
| P1 · 应用验证 | 在冻结生物集合上进行独立河网匹配及水/生物预测对照 | 先检验应用链路中哪一步成立 | 决定是否进入已知来源测试 |
| P2 · 来源与迁移 | 在独立基准支持后推进来源候选范围与具体迁移案例 | 避免单一成功案例代替适用性证据 | 形成可解释的科研应用交付 |
| 条件性 · 模型扩展 | 仅对有新信息或新需求证据的分支重新立项 | 当前失败不支持无限调参或照搬未验证的信息层 | 新实验必须定义独立验证、预算和停止条件 |

修正实验等早期指标采用各阶段最终 RESULTS；后续引用范围见[执行记录说明](../evaluation/later-research-records.md#材料范围)。
