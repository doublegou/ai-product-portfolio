# 实验与决策时间线

我按实验阶段整理了路线演进，关联原始优化笔记与正式 RESULTS / release 记录。每一步都明确当时要回答的问题，以及结果如何改变下一步投入。

| 阶段 | 所问问题 | 记录中的结论 | 对路线的影响 |
| --- | --- | --- | --- |
| Base V0/V1 | 现有特征能否支持空间或水系外推 | 高值尾部仍明显低估；验证条件不同 | 将高值能力单独检验 |
| Global High-Sr Risk | 非坐标变量是否支持跨水系识别高值 | 两类候选均为 0/3 repeats 通过 | 不建立生产分类器 |
| High-Sr Correction | 二层非负修正能否改善原始模型 | 有残差信号，但四个候选均未通过 Raw Base 安全门槛 | 不发布 correction |
| Base V2 | 新支流条件下的泛化是否不同 | Purged Branch 与 Matched Terminal 对照改善，但极高值仍漏检 | 区分支流与完整水系的应用条件 |
| Regional Risk V1/V1.1 | 区域排序信号是否达到实际判别门槛 | 存在排序信号，但未通过完整 Gate | 不等同可部署区域专家 |
| Regional Risk V2 | 更强算法与 Process14 是否能解决问题 | 四个候选均不合格 | 开展失败审计 |
| Failure Audit | 漏检系统是否缺少可区分信息 | 记录支持当前特征的信息缺口 | 停止同特征集下继续调参 |
| Base V3 | 增加覆盖后，RF 与 XGBoost 如何选择 | 选择 RF，但仍存在严格高值迁移限制 | 连续回归保留，高值筛查用途受限 |
| Direction 2 | 哪些信息具有稳定、可迁移的预测价值 | 后续方案，尚无对应最终结果 | 扩展特征与更严格确认设计 |

## 已核对的关键口径

1. Base V3 从 4,485 到 5,600 站点的数据构成和清洗口径。
2. RF 与 XGBoost 的 pooled OOF RMSE：0.017235 与 0.017723；比较必须保持同一实验设计。
3. 严格站点均值 OOF 中，两个模型均漏掉全部 29 个 Sr ≥ 0.80 站点及 5 个极高值水系。
4. Correction 在对应残差对照上改善，却未改善 Raw Base；需要同时展示两类对照。

Base V3 站点数为 5,600，四段数量为 4,756 / 708 / 107 / 29；从重复摘要复核 pooled RMSE；与 final manifest 核对 0/29、0/5。修正实验采用最终 corrected_r1_final 的 −0.95%（Full50 残差 RF 相对 Raw Base），原笔记保留前次运行 −1.64%，不混用。详见 [验证记录](../evaluation/README.md)。

以上指标来自正式冻结运行。Direction 2 的 Core、lockbox 与信息贡献分析仍属于后续设计。
