# RiverSR 案例初稿

状态：基于本人提供的过程笔记和仓库说明整理；实验数字待与输出文件逐项匹配。

## 问题定义

一个在已有站点上拟合良好的模型，能否迁移到未采样支流或完整陌生水系？尤其在高 Sr 样本稀少且集中时，总体误差是否掩盖关键场景失效？

案例把科研验证与产品判断连接起来：使用场景决定评估方式，评估结果决定交付范围，而不是用训练效果代替部署可信度。

## 三项关键判断

### 验证设计应对应使用条件

空间分组、完整水系留出和下游隔离的支流验证代表不同迁移问题。Base V0/V1/V2 改变了主要验证方式，不能把不同分布下的分数直接画成模型性能提升曲线。支流结果改善可以帮助解释适用条件，但不证明完整陌生水系问题被解决。

### 局部信号不等于可接受的改进

过程记录中，二层 correction 相对其 BasePred-only 对照发现了残差信号，却未通过相对 Raw Base 的安全门槛。这个决策适合说明：实验对照的选择会改变结论，局部改善不能覆盖总体退化。

### 失败诊断决定是否继续投入

区域模型经过 GAM、RF、XGBoost 和 Process14 的尝试仍未达到完整验收要求，后续审计发现漏检高值站点与背景在现有特征中高度重叠。记录据此停止围绕相同 predictors 继续调参。应写成该项目证据支持的信息不足判断，不声称证明所有算法必然无效。

## 最终交付边界

记录中的 Base V3 比较选择 RF，明确保留高 Sr 限制。训练拟合能识别极高值，不意味着严格陌生水系验证也能识别；最终需要同时交付模型能力与限制说明。

地图前端当前是独立交互原型。未来如需展示真实预测，先确定可公开数据与模型输出，再验证输入、计算分值和地图渲染一一对应；此次不修改地图源码。

## 后续方案

Direction 2 从追求全球模型精度，转向识别稳定预测信息及其迁移边界。Core discovery、独立确认、域泛化与条件性专家模型是规划，不填写未完成的通过率或成果。
