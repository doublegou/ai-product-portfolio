# RiverSR：把模型表现转化为可用范围

[返回项目](../README.md)

## 用户任务与产品定位

科研使用者面对的是稀疏采样：已有地点有观测，新的支流或完整陌生水系没有观测，希望利用环境信息获得连续估计，并决定是否继续采样。模型结果应同时交付数值、适用条件和失败风险。现阶段是研究工作流与应用原型，没有证据支持活跃用户、业务转化或生产服务承诺。

产品化最关键的界限是区分两类问题：连续比值估计与高值水系发现。前者用误差评价，后者必须看召回、误报和覆盖到的独立水系。如果把它们合成一个“准确率”，低值占多数的数据就可能掩盖高值漏检。

## 从任务倒推验收设计

| 使用条件 | 验证问题 | 设计含义 |
| --- | --- | --- |
| 已有观测的大水系内出现新支流 | 是否利用了下游泄漏或共同背景 | Base V2 使用 downstream-purged branch 设计 |
| 完整陌生水系 | 能否迁移到独立水系背景 | Base V3 内外层均隔离 MAIN_BAS 水系 |
| 新区域或新资料来源 | 结果是否依赖空间邻近与采样来源 | 固定配方做空间分块和 reference 分组压力测试 |
| 发现 Sr ≥ 0.80 的极高值 | 是否真的找到稀少高值及其水系 | 分别报告站点与水系命中，不能只看 RMSE |

这些是不同部署情境，不能把 V0、V1、V2、V3 的分数连成一条性能增长曲线。Base V2 的支流结果也不能作为 Base V3 陌生完整水系的承诺。

## 决策一：先保证比较公平，再决定是否换模型

Base V3 对 RF 与 XGBoost 使用相同外层分组和 48 粗筛 + 16 细化结构的搜索预算；权重方案也在内层选择。外层测试只在候选冻结后使用，防止测试集参与选型。

RF 的 pooled RMSE 从 XGBoost 的 0.017723 降至 0.017235，相对降低 2.76%，3 次重复方向一致。选择 RF 的依据是预先规定的严格 OOF 比较；不是“树模型更容易解释”之类事后理由。这个优势仍然有限：R² 仅 0.0800，高值识别没有改善到可用程度。

## 决策二：有信号不等于值得发布

二层高值修正有两个对照。相对同算法 BasePred-only 残差对照的改善，回答额外环境信息有没有残差信号；相对原始 Raw Base 的改善，回答用户最终会不会得到更好的模型。

最终运行里，Full50 残差 RF 的前者为 +21.76%，后者为 −0.95%，安全门槛仅 1/3 次重复通过。因此不训练全数据修正模型、不发布修正包，保留原基线。其他三个候选同样未通过。完整负结果来自[正式实验记录](../src/river_sr/training/global_correction/high_sr_correction_feasibility/RESULTS.md)。

这项决策避免把一个漂亮的局部指标升级为不成立的产品能力。优化笔记保留了前一次运行的数值；本作品集使用最终验收运行，并在时间线说明版本差异。

## 决策三：尾部失败决定用途限制

5,600 个站点中 4,756 个低于 0.72，只有 29 个达到 0.80。RF 能在全数据训练拟合中命中全部 29 个极高值，但在严格站点均值 OOF 中为 0/29，水系为 0/5。模型的拟合容量不能解释这道迁移鸿沟。

据此把发布范围限定为全球连续 Sr 回归研究基线，不批准高值系统发现、极值分类或风险筛查。地图产品若接入该模型，也必须继承这一限制；不能把连续估计直接改名为“高风险概率”。

## 地图与研究模型之间还缺什么

当前地图原型有输入、计算、渲染模块，使用合成场；展示颜色未直接使用查询 score。这是明确的未接通接口。研究模型提供 50 特征到连续值的映射；同位素来源推断则需要测量误差、预测不确定性、空间先验与合适的似然假设，不能直接用回归点估计替代。

接入前至少需要：统一坐标与特征提取；随结果返回模型和数据版本；标识不支持的输入域；建立可校准的不确定性；让地图颜色绑定实际查询输出；端到端验证同一输入是否产生预期结果。这些是产品化验收条件，不是已交付能力。

## 下一阶段为什么转向信息而不是继续调参

已完成的区域专家与修正实验没有通过门槛，双算法都无法外推极端尾部。Direction 2 因此提出：扩展候选信息，比较地质、水文、河网混合、气候、人类活动与空间代理的独立贡献；使用嵌套筛选稳定特征；冻结后交给独立水系确认集。

这份方案的价值是让后续投入围绕可验证的新假设。候选特征或确认集尚未产出正式结果前，不使用“识别了关键驱动因素”或“泛化已提升”的措辞。预测关联也不能自动升级为因果结论。
