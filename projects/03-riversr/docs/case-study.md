# RiverSR：从科学问题到可迁移的预测模型

[返回项目](../README.md) · [数据与技术方案](technical-design.md) · [研究演进与后续规划](decision-timeline.md)

## 研究背景与目标

RiverSR 是实验室与中科院合作背景下的科研项目。我独立承担这里展示的数据处理、特征工程、建模验证与应用探索，研究对象是全球河流站点的连续 ⁸⁷Sr/⁸⁶Sr 比值。

研究的起点是采样覆盖与预测需求之间的差距：已有观测集中在有限地点，但需要判断的对象包括未采样支流、陌生水系和不同地理环境。我的工作是把这个空间预测问题转成有明确输入、测试条件和交付标准的机器学习流程。

我将成功标准分为三层：数据能够稳定更新；模型表现能够在明确的未见环境中检验；研究结论能指导下一轮数据和方法投入。地图是成果使用方式的探索，模型是否可信仍由隔离验证决定。

## 一、先定义研究问题，再安排实验

### 把一个“大模型任务”拆成可回答的问题

| 问题 | 实验对象与对照 | 可以支持的结论 |
| --- | --- | --- |
| 环境特征能否支持连续预测？ | Full50 基线；固定任务下的 RF / XGBoost 比较 | 在该数据和验证条件下，哪套配方误差更低 |
| 尾部低估能否单独解决？ | 非坐标高值分类；二层修正与未修正基线 | 能否识别高值，修正是否改善最终交付 |
| 新支流与陌生水系是否同样困难？ | Naive Branch、Purged Branch、Matched Terminal | 验证单元与水文连接如何改变泛化条件 |
| 区域化与过程特征是否有额外价值？ | 区域 GAM；RF / boosting × Full50 / Full64 | 更强非线性和现有过程衍生变量能否改善跨支流识别 |
| 下一笔研究投入放在哪里？ | 冻结失败样本的特征重叠与跨支流近邻诊断 | 当前表示是否缺少可区分信息，是否值得继续同路线调参 |

这些实验逐步缩小解释范围。单次模型失败不能推出某个科学机制不存在，多次相同方向的证据则可以帮助决定是否继续投入。

### 为什么分别验收连续值、排序和高值识别

连续回归用 RMSE、MAE、Bias 与 R² 判断误差；风险排序看 PR-AUC 等排序质量；真正用于筛查还需要在限定误报下达到召回、精确率和独立水系覆盖要求。三者对应不同使用任务。

以区域实验为例，只在少数支流找到很多高值，可能让整体指标看起来不错，却不能帮助进入新的高值支流。因此我同时评价站点表现与支流覆盖，并在看测试结果之前冻结门槛。这里的门槛是实验准入标准，不是经过真实业务试点验证的效益阈值。

## 二、数据工程：从采样记录到模型可用的环境表示

基础数据从 6,283 条原始观测按坐标聚合、连接预测因子，形成 4,527 个候选站点，其中 4,485 个进入初版 Full50 训练。后续九来源的 1,950 条补充观测经重复排查与河网匹配，新增 1,115 个站点，得到 5,600 站点版本。

我把三类容易混淆的对象分别保存：原始观测、聚合后的站点、按流域和河网构建的环境特征。这样，同一个站点的重复记录不会直接变成多个独立训练样本，数据扩充也不会静默改变旧站点的响应值。

特征构建同时考虑**局地条件与上游背景**：例如局地和上游岩性、地质年龄，以及流量、汇水面积、河网位置、气候、土壤和地形。河网拓扑也用于建立验证分组。这种局地与上游的组织方式，与 HydroATLAS 对流域属性和河网连接的表达一致；本项目实际采用的输入与提取规则以代码和 Full50 清单为准。[HydroATLAS 数据论文](https://www.nature.com/articles/s41597-019-0300-6)

数据规模并不能替代独立环境覆盖：Base V3 中 Sr ≥ 0.80 的 29 个站点只来自 5 个水文系统。因此我保留水系维度的支持数，并把高值作为单独诊断对象。[构建规则与特征来源](technical-design.md#数据如何形成)

## 三、验证设计：让评估对应真正要使用的环境

### 新支流：保留可用背景，清除下游信息

完整水系留出适合评价“进入全新水系”，但会同时移走许多原本可用的支流背景。Base V2 针对另一种场景：在已有部分观测的大水系内，预测尚未采样的支流。

我用不读取响应值的拓扑规则定义 branch，在测试支流之外剔除其下游训练站点；内层调参也遵守相同隔离，防止外层没有泄漏、内层却利用了下游信息。比较设置为：

| 对照 | 保留或移除什么 | 回答的问题 |
| --- | --- | --- |
| Naive Branch | 留出测试支流，保留其他站点 | 未清除下游连接时会得到什么结果 |
| Purged Branch | 进一步清除测试支流的下游训练站点 | 严格支流隔离后的表现如何 |
| Matched Terminal | 在匹配测试条件下移除完整相关水系 | 更保守的水系隔离与支流场景相差多少 |

三个尺度、九套设计中，Purged Branch 在 RMSE、MAE、高值绝对偏差及 branch-macro RMSE 四项上都优于 Matched Terminal。与此同时，它没有稳定优于 Naive Branch：正式 primary_s05 中，下游剔除使 RMSE 增加约 2.47%。我保留剔除规则，因为它对应更可信的验证条件。

最终 Base V2 在 2,577 个 branch-eligible 站点上的站点均值 OOF RMSE 为 0.0133358，R² 为 0.424667。这个结果支持新支流场景的研究基线，不能直接推广为完整陌生水系的表现。[正式实验](../src/river_sr/training/base/v2/RESULTS.md)

### 陌生完整水系：将模型选择与最终测试分开

Base V3 在 5,600 站点上采用完整水系隔离的重复嵌套验证：外层留出水系，内层选择参数和样本权重；缺失值处理只拟合当前训练分区。RF 与 XGBoost 每个外层任务均用 48 个粗筛结构、16 个细化结构，并比较三个权重方案。

严格外层预测选择 RF：pooled RMSE 0.017235 对 0.017723，3/3 次重复方向一致。但固定配方的 reference 分组压力测试中，XGBoost 更好。这提醒我，算法优劣取决于迁移任务；当前主任务是完整陌生水系，来源迁移作为另一条风险轴报告，而不据此重新调参。[科学设计与结果](../src/river_sr/training/base/v3/RESULTS.md)

## 四、三次改变路线的判断

### 1. 用正确对照，防止把中间环节的提升当成最终收益

高值修正实验先用严格 cross-fit 生成 Base 预测，再学习非负修正量。实验设置两个独立门槛：

- 相对 **BasePred-only 残差对照**改善，检验环境特征是否提供额外残差信号。
- 相对 **未修正 Raw Base**改善，检验最终预测是否真的更好。

Full50 残差 RF 相对前者平均改善 21.76%，相对后者却为 −0.95%；四个候选均未通过最终安全门槛。因此我没有把这条路线继续推进为全量修正模型。

这还是一个使用真实 elevated-Sr 条件筛选的 Oracle 可行性实验，不能直接当成部署时可用的高值入口。部署场景并不知道真实 Sr，必须另有可泛化的识别环节。[修正实验](../src/river_sr/training/global_correction/high_sr_correction_feasibility/RESULTS.md)

### 2. 让流程约束决定模型是否有用

区域实验固定喜马拉雅的 372 站点、17 个支流，其中 14 个支流包含高值。区域 GAM 的排序信号促使我继续验证校准与阈值；未达到筛查条件后，再比较 RF、浅层 boosting 和新增 Process14。

Regional Risk V2 的准入要求同时满足：背景误报 ≤10%、高值召回 ≥60%、精确率 ≥30%、阳性支流覆盖 ≥9/14，以及极高值系统覆盖 ≥2/4。最接近的 RF Full50 达到 6.96% 误报、45.54% 召回、45.78% 精确率，但只覆盖 6/14 个阳性支流，仍未通过。

更值得注意的是，Full50 boosting 的 AP 和 AUROC 更高，却没有达到更好的筛查门槛表现。因此我没有只按排序分数选模型，而是保留不同模型适合或不适合承担的任务。[区域最终结果](../src/river_sr/training/regional_expert/regional_risk_v2/RESULTS.md)

### 3. 过程假设要接受数据检验，不能靠名称获得解释力

Process14 将“源区—河网传递—汇流与稀释”的设想编码成上游/局地面积关系、单位面积流量、地质年龄及岩性差异等变量。在 RF 与 boosting 中加入它们后，排序和召回都没有改善。

我对冻结的漏检集合继续做诊断，而不重选阈值：8 个完全漏检的阳性支流包含 28 个高值站点；这些站点的 Full64 特征落在普通背景 5%–95% 区间的比例中位数为 95.3%。排除同支流后，其五近邻的高值比例只有 6.4%，低于区域站点高值比例 21.5%。

这些证据支持当前特征对漏检样本的区分不足。Process14 由已有输入衍生，它的失败并不意味着水文—地质过程不重要；更合理的下一步是检查新的过程测量和空间支持，而不是继续扩充同一批输入的算法组合。[失败诊断](../src/river_sr/training/regional_expert/regional_failure_audit/results/FAILURE_AUDIT.md)

## 五、把研究成果转成可使用的交付

我将交付拆为数据、方法、结论和应用四层：数据版本支持更新与复查；冻结配方和运行工程支持重复实验；分场景结论帮助使用者判断适用范围；地图原型探索查询与解释方式。

当前可以交付连续预测研究基线及其适用条件。高值发现没有通过验证；地图使用合成场且颜色尚未绑定真实查询分值，尚未形成模型服务。接入时需要明确两种不同任务：

| 应用任务 | 输入与输出 | 进入下一阶段的条件 |
| --- | --- | --- |
| 给定位置估计 Sr | 坐标 → 同版本环境特征 → 连续值、模型版本和输入域提示 | 特征管线一致；已知站点可核对；不支持区域有明确反馈 |
| 给定同位素条件探索来源 | 测量值及误差 → 候选空间分布 | 增加预测不确定性、空间先验与似然设计，并用已知来源样本校准 |

回归点估计不能直接充当真实来源概率。地图的接入顺序是先统一查询输出与渲染，再接特征和模型，最后验证误差传播与空间解释。[现有产物与界面](../demo/README.md)

## 六、研究如何继续

Direction 2 将问题推进到“哪些信息具有稳定、可迁移的预测价值”。我规划先比较信息模块，再选择稳定核心变量、独立确认精简模型，最后测试不同环境域。关联分析单独设计，避免把预测重要性当成因果解释。

优先投入能够改变研究结论的信息：新增数据能否提高独立水系支持，新增特征是否提供超出位置代理的增量，失败是否来自训练覆盖之外。只有更稳健的全球特征仍不能解决迁移、且存在域间关系差异的证据时，才重新考虑专家模型。[完整阶段规划与确认集约束](decision-timeline.md#下一阶段direction-2)
