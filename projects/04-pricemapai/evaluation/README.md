# 公开快照回放与工程验证

[返回项目](../README.md) · [指标解释与下一轮实验](../docs/metrics-and-experiments.md)

这次评估回答三个问题：公开版本能否完整加载；当前数据支持什么程度的价格比较；更新中断或数据损坏时，现有规则怎样处理。

## 可重算的输入

- 来源：`https://pricemapai.com/data/latest.json` 及其引用的全部 19 页公开 gzip 数据。
- 采样：2026-10-17 13:47:16（北京时间）；版本生成于当日 13:30。
- 版本：`60a34fcc025c6b996c76c405`；生产源码：`3c97c452105bce6626ec2c81ef7c940829ddc7a5`。
- [采集清单与 SHA-256](fixtures/public-snapshot-20261017/capture.json)、[版本清单](fixtures/public-snapshot-20261017/latest.json)、[回放代码](replay-snapshot.mts)、[完整结果](snapshot-replay.json)。

回放直接调用原生产加载器、有效期、同规格最低价、目录分类与 API 展示规则；计算时间固定为采样时刻，所有读取限定为本地归档。它验证公开数据与产品规则，不代表已经逐家确认原站商品，也不验证 API 模型身份。

## 结果

| 维度 | 观测 |
| --- | --- |
| 订阅覆盖 | 4,822 条报价；360 个商家标识；45 个类别有报价 |
| 当前规则下有效 | 4,749 条未过期；2,873 条同时有货 |
| 严格比较 | 6 条资格合格；0 个至少两家来源的可比组 |
| API 覆盖 | 27 家站点、3,319 条报价；25 家站点在有效期内 |
| 成本表达 | 1,809 条能计算现有综合系数；其他保留复杂 / 缺失条件 |
| 版本体积 | gzip 735,986 B；解压 8,682,203 B |

目录起价与详情严格最低价存在语义差异：41 个类别显示最低价，39 个选择的报价仍待复核。这是优先修正规则表达与规格覆盖的依据，不能将目录数量当成准确比价能力。完整解释见[质量诊断](../docs/metrics-and-experiments.md#质量诊断决定优先级)。

## 边界与失败处理

| 方法 | 输入 | 结果与含义 |
| --- | --- | --- |
| 真实快照 | 清单与全部分页 | 哈希校验通过，生产加载器接受，报价 / 站点 ID 唯一 |
| 构造故障 | 首个分页缺失 | 重读清单后仍失败，拒绝结果 |
| 构造故障 | 分页版本与清单不同 | 重读后仍不一致，拒绝混版 |
| 构造故障 | 分页内替换出重复报价 | 拒绝重复数据 |
| 时间模拟 | 相同快照不更新，推进 60 分钟 | 有效报价降至 4,363 条，其中有货 2,620 条；证明有效期会自然失效 |

后三类故障与时间推进为离线构造实验，不是线上事故。时间模拟没有实际等待并再次抓取原站。
