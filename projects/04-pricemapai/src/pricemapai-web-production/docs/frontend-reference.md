# PriceMap AI · 前端设计原型

浅色极简的 AI 订阅比价原型：双入口首页、卡网套餐目录、渠道报价详情、API 服务商目录。独立于 `aimarketing`，没有修改其前端、Worker 或数据库。

## 运行

Node.js 22.12+。

```sh
npm ci
npm run dev
```

默认地址：`http://127.0.0.1:5173`。

```sh
npm test
npm run build
npm run preview
```

构建产物在 `dist/`。如需自行静态托管，所有非资源路径须回退到 `index.html`，以支持详情页刷新。当前只提供本地预览，未部署。

## 页面

- `/`：上方卡网入口、眼睛跟随鼠标的卡通圆球与可点击平台 Logo，下方 API 图片环形轮播；不再重复模块介绍与精选套餐。
- `/subscriptions`：平台与商品分类、搜索、交付、时长、库存、人民币价格区间、排序与分页。
- `/subscriptions/:productId`：渠道报价、规格筛选、商品原文展开、商家外链。
- `/api-pricing`：官方 API / 中转渠道分类、服务商与模型搜索、模型筛选、官方价格展开和来源链接。

筛选保存在 URL。进入详情后的返回链接保留目录条件。移动端导航、原生信息弹窗和减少动态效果模式均可用。

## 数据

当前为 **演示数据**：128 条演示报价、8 家商家、13 个订阅套餐、2 个辅助分类及待归类分类。商家名称与首页链接来自原项目 `config/verified-sources.json`，字段保留其公开 Offer 结构。价格、库存、时间和商品标题是原型样例，不能用于实际购买决策。演示外链指向商家首页。

原项目公开接口在制作期间连接超时，因此使用已批准的示例兜底方案。原型包含读取公开接口的脚本：

```sh
npm run snapshot
```

脚本遍历所有分页、按 ID 去重，成功后原子写入 `src/data/snapshot.json`；失败不覆盖已有数据。重新启动或构建后优先读取该快照，UI 不显示开发阶段的数据标记，数据性质仅在本文档及源数据中保留。不读取密钥、不连接数据库、不写入原站。运行时所有页面、数据、字体均为本地资源。

演示的有效期判定固定在样本时间 `2026-10-07 16:00 Asia/Shanghai`，确保样例中的有效、过期、缺货与未知状态可重复查看；真实快照按打开页面时的实际时间判定。没有伪装实时刷新。

## 比价与归类

标准商品目录与原始 Offer 分开保存。`src/data/standard-products.json` 逐项记录 2026-10-08 查阅 PriceAI 得到的 50 个业务类目，未复制报价。ChatGPT 包括周边服务、普号、Plus 成品号、Team/Business、Go、Codex 额度、Plus 充值与 Pro 100/200/500 刀档；其他平台也保留独立档位。没有报价的类目仍显示入口；未明确档位的报价进入其他商品，不根据售价猜测档位。

当前订阅界面只载入人民币报价，移除币种标签和切换；源数据保留原币种字段，未对其他币种做假换算。“参考价格”仅汇总有货且有效的标价，仍可能包含不同交付与时长，不等于同规格最低价。后者要求有效 `comparison_key`、非待核验、同币种、同交付、同时长、至少两家独立来源。最低价计算不把过期、缺货或未知库存纳入，也不推断质保。

## 结构

- `src/pages`：各页面；`src/components`：导航、列表、品牌图片及环形轮播。
- `src/data`：原始字段、演示数据、标准套餐映射及可选真实快照。
- `src/lib`：归类、汇总、最低价。
- `src/styles.css`：基础布局；`src/glass.css`：液态玻璃主题；`src/redesign.css`：双入口首页与紧凑信息目录。
- `tests`：归类、价格可比性、异常状态与外链处理测试。

使用 React、TypeScript、Vite、React Router、Lucide 和本地 DM Sans 字体（通过 Fontsource 提供）；首页使用系统字体与苹方中文字体搭配，标题统一 600 字重；其余界面保持 DM Sans 与系统中文字体。无登录、交易、采集调度或后台功能。

## 视觉资源与轮播

首页上半区采用 [Grok Ball](https://github.com/tycoding/grok-ball) 的开源 SVG 表情球引擎，源文件保存在 `src/vendor/grok-ball`，MIT 授权见 `third-party/grok-ball`。保留原始眼形插值、眨眼与球面投影；本地扩展修正轮廓为正圆、眼形居中扶正，并校准默认双眼比例、提升鼠标视线响应与范围；本地 React 组件接入鼠标跟随、平台聚焦与点击表情，默认双眼使用同一个左眼轮廓，无悬浮提示文案；每隔 12 秒短暂展示一种日常表情，点击依次体验全部原始表情（每次保留 8 秒），并配置不含自动自旋的安静待机状态。页面离屏、后台或减少动态效果模式下暂停持续渲染。这不是 OpenAI 官方素材。

全站通过 `prefers-color-scheme` 跟随浏览器/系统明暗偏好并实时切换。浅色主题使用黑色小球，深色主题使用白色小球；球身保持固定尺寸，关闭呼吸缩放和点击弹跳，保留眼部表情与跟随；目录、报价、筛选、弹窗、Logo 和轮播均适配暗色。

ChatGPT、Claude、Gemini、Grok、Cursor 五个原始透明 Logo 放在小球周围的透明泡泡中，可直接进入对应平台筛选。泡泡使用细虹彩边缘、曲面反光和透明中心，支持错相漂浮、指针反光、悬停抬升、按下反馈及键盘聚焦（无箭头或外圈）；角色会看向聚焦的平台。原先的 CSS 大眼圆球和白底圆片已替换。

下半区使用用户提供的 [React Bits Circular Carousel](https://reactbits.dev/components/circular-carousel)，采用 cylinder / rise、拖拽、惯性、悬停暂停和键盘操作。六张 4:3 横向图片（基础宽度 320px，随容器自适应缩放）暂作 API 视觉占位，不展示底部说明或播放按钮，点击或回车进入 API 目录。摄影资源保存在 `public/images`，来源见同目录 `ATTRIBUTION.md`。

API 服务商数据保存在 `src/data/api.ts`，按官方 API 与中转渠道分类。部分官方模型的公开价格于 2026-10-07 查阅官方文档后写入本地，保留计费单位、时段、有效日期和原始链接；没有收录的中转倍率和可用性显示缺失状态，不生成模拟数值。渠道组织参考 https://priceai.cc/api-transit 与 https://priceai.cc/official-api。

平台图标使用 [LobeHub Icons](https://github.com/lobehub/lobe-icons) 的原始透明 SVG，复制到 `public/logos` 本地引用，不再手绘或运行时访问 CDN。文件与版本见同目录 `ATTRIBUTION.md`。首页、列表、详情共用这些资源。

液态玻璃效果通过透明渐变、背景模糊、色彩饱和、内侧高光与柔和投影组合，文字本身不施加模糊。界面已按要求移除演示、原型和快照标记。数据仍是设计样例，未来对外正式上线前需要替换为真实报价。

首页卡网按钮采用用户提供的 btn-17 斜切翻色与文字滚动效果，保留链接语义、键盘聚焦和减少动态效果支持。字体参考 Apple 中文站 CSS 中的 SF Pro / PingFang SC 字体组合与 OpenAI 品牌字体规范（https://openai.com/brand/），不打包专有品牌字体。

目录按固定业务大类组织卡片（例如 Plus 成品号、Plus 充值、Pro 各档位）；日抛、月卡、年卡与交付方式进入类目内的报价筛选，不再各自生成卡片。宽屏六列，一页 24 项。目录与详情筛选使用支持键盘的液态玻璃下拉菜单。收藏功能已移除，首页说明改为报价时间。

目录支持网格／列表切换，显示模式保存在 URL，进入详情再返回仍保留。卡片右上角显示商家与报价数量；最低价取类目内有效有货报价的最低值，详情中的同规格最低价仍按严格可比条件计算。目录不再展示库存标签、结果范围或价格说明，只有多页时显示翻页按钮。下拉菜单与触发按钮等宽。

品牌标识改为地球叠加 AI；地球及全部、邮箱、接码、其他分类使用 [Phosphor Icons](https://github.com/phosphor-icons/react) 的现成双色图标（MIT，`@phosphor-icons/react`），跟随全站明暗主题。

列表使用商品、交付方式、状态（商家／报价数量）、最低价、更新五列表头，滚动时吸附在固定导航下方。显示模式使用单按钮切换；列表和网格的更新时间按实际当前时间显示相对时间，每分钟刷新一次。

目录现采用桌面侧边平台导航，小屏回退为可横滑标签。同系列入口在 `src/lib/catalogGroups.ts` 聚合：Plus 成品号／充值、Pro 各档，以及 Claude Max／Team、Gemini Pro／Ultra、SuperGrok。详情顶部标签分别显示原标准类目的报价，URL 保留所选标签和返回目录条件；旧的子类详情链接仍可访问。
