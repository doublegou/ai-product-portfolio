# 多店平台接入记录

核验日期：2026-10-07。PriceAI 公开商家页面仅用于定位候选店铺网址；店名、商品、库存和价格重新从原商家公开接口取得。采集器独立实现，没有将对方生产报价写入本站。

## 本轮结果

核验了 316 个 16688 候选店铺：311 家原站可用，其中 209 家至少包含一个标题明确涉及 ChatGPT / Claude / Gemini / Grok / Cursor / Codex / OpenAI 的商品，已启用并完成线上采集；102 家本轮没有这些相关商品，未启用；5 家原站店铺不可用。别名店铺 `MENGZE` 经原站 `/shopApi/shop/detail` 确认对应 `S528762`，以该真实店号接入。

本轮新增 209 家、3,307 条商品报价。连同原有 27 家、463 条，目前共 236 家来源、3,770 条商品报价。数目包含邮箱、其他工具以及店内非 AI 商品，不能称为 3,770 个 AI 会员套餐。线上核验分页共 4 页，合计 3,770 个唯一报价 ID，与 API 总数一致。

已验证的来源配置位于 `config/verified-sources.json` 和 `supabase/seed.sql`，只保存原站核验后的店名、完整店铺地址和采集配置，没有固化价格快照。

## 原站接口与报价口径

- 页面入口：`https://www.16688.com.cn/shop/S店号`；不同店号独立来源，同域名不去重成一家。
- 原站自身客户端调用 `POST /shopApi/shop/detail`，请求 `shop_no`，用于核验真实店名和店号。
- 原站自身客户端调用 `POST /shopApi/goods/list`，请求 `shop_no`、空 `goods_category_no`、空 `keywords`、`sort: default`。该公开列表无分页参数，返回该店全部列表；将其作为完整快照，异常和空列表保留旧报价。
- `goods_no` 为商品标识，`name` 为原始标题，`price` 为公开标价，`stock_available_quantity` 为库存，购买链接为 `/goods/G商品号`。单店最多 500 件，未知库存不推测为有货。
- 16688 商品标价可能另有由买家承担的平台手续费。前台商品卡片和详情显示提示；没有验证最终手续费前，这些报价不参与同规格最低价比较。
- 邀请码、资格、虚拟卡和接码商品保留原始标题，但套餐、交付归为待确认，不与会员订阅进行最低价比较。支持 `GP.T` / `G·P·T` 与 Google AI 的标题识别。

## 未启用的 ShopApi 候选

当前 `wzyp.cn` 和 `pay.ldxp.cn` 的原站入口及旧版接口返回 WAF 验证页，未得到可验证的商品列表。不能把 HTML 验证页当成接口成功，也不能假设旧版 `/shopApi/Shop/goodsList` 适用于其当前版本。没有批量启用这部分来源。后续需要商家提供公开接口或授权的可用采集方式。

## 调度与分页

Cloudflare Cron 每 5 分钟领取最多 8 家到期来源；数据库领取上限同步改为 8，单店手动采集只领取该店。新增 209 家设置每 720 分钟刷新，原有每小时／6 小时来源保留自己的间隔。理论容量 96 家／小时，本轮正常刷新需求约 27 家／小时，失败退避和平台限制另计。每家仍记录独立租约、运行结果和成功时间。

公开报价 API `GET /api/offers?limit=1000&offset=0` 返回 `offers`、`total` 和 `next_offset`，使用 ID 排序；前台自动顺序加载所有页并去重。`limit` 限制为 1–1000，负数或非整数参数返回 400。采集期间不同页可能观察到不同数据库时刻，重新刷新后会收敛；不会宣称跨页是同一数据库事务快照。
