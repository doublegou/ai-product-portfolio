## 一条任务的实际产物

2026-09-25 的演示导入 `sales` 音频（界面显示约 01:23），产出分段转写及“家庭保障方案推荐”摘要；之后展示回听、分享入口和收藏。资料库还展示录音入口。介绍视频是已经剪辑的历史演示，不能据此推算端到端速度。

## 版本与证据边界

视频中展示 App Store 1.0.2；本仓库另有后续工程快照。视频不能证明当前模型配置、Android 端或每种导出格式均达到同样效果。素材里的“最高 60×”没有配套固定样本和日志，不进入测量结果表。

原始目录含 168.62 秒介绍视频与 521.67 秒录屏素材。作品集保留完整介绍视频与选定关键帧；大体积源文件保持本地，不重复入库。使用演示谈话内容仅用于展示功能，不作为真实客户研究或转写准确率标签。

## 有价值的后续补录

现有素材已经能展示常规流程，暂不需要堆更多同类截图。后续真正增加证据的是：当前版本同一段音频的完整运行、切后台后的恢复、摘要失败但转写仍可用、Android 抽取降级的实际界面。录制时包含版本和设备，保留连续过程；这些目前属于待验证材料。
