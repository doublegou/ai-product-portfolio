# StayWord

**把录音变成可核验、可复用的本地笔记。**

一款已上架的端侧 AI 录音产品：录音 / 导入 → 转写与摘要 → 回听核验 → 编辑、分享和整理。产品设计与双端工程独立完成，iOS 已有发行、真实反馈与经营数据。核心挑战是让小模型在手机资源与后台限制下，交付用户能继续使用的结果。

## 从反馈到版本：优先补上结果的使用环节

历史反馈指向三个任务：更快回听、把结果带走、在自己的设备上使用。版本的价值因此不只在转写和摘要生成，也在核验、复用和使用条件。

| 用户信号 | 产品选择 | 实际交付 / 取舍 |
| --- | --- | --- |
| “音频倍速播放” | 让用户更快核对原话 | 0.5–2× 六档倍速、偏好保存、锁屏播放速率同步 |
| “录音、转录和总结分享” | 用户选择需要的材料，而非只复制一段文本 | 原音频、带时间戳转写 TXT、摘要 TXT；空内容和文件失败分别处理 |
| 付费用户要求 iOS 16 兼容 | 记录需求，但不承诺未经适配的设备能力 | 历史版本决定不做，当前要求 iOS 18+ |
| 收音问题、手表录音 | 分开处理采集质量与新设备场景 | 收音需要分层诊断；手表仍属待验证需求 |

**MVP 的闭环是“记录—理解—核验—复用”，范围外是云同步、团队协作和手表端。** 本次将原始需求表整理成可追溯的需求池，并补齐任务假设、验收与重开条件；不补造历史访谈人数。[用户研究、MVP 与完整需求池](docs/product-discovery.md)

## AI 如何工作，失败后留下什么

![StayWord 双端处理链路与降级分支](demo/assets/architecture.svg)

| 环节 | iOS 工程快照 | Android 工程快照 |
| --- | --- | --- |
| 音频与转写 | AVFoundation → 16 kHz 单声道 PCM → Silero VAD → SenseVoice；Sherpa ONNX | MediaCodec / PCM → Silero VAD → Pyannote + 3D-Speaker → SenseVoice；Sherpa ONNX |
| 摘要 | Qwen3.5-0.8B 4-bit / MLX；约 10,000 字符分块，长输入分段总结再整合 | 前台且 AICore 可用时尝试系统生成；否则 Qwen3-0.6B INT4 / LiteRT-LM；GPU 失败尝试 CPU |
| 降级交付 | 摘要失败后保留转写，单独保存摘要错误 | 生成失败或结果与原文归一化后完全相同：确定性抽取摘要，保存类型 |
| 长任务 | 前台串行 FIFO；切后台取消计算、保留转写检查点，返回后续跑 | WorkManager 全局串行链；恢复任务重新进入处理流程 |
| 持久化 | SwiftData + 音频文件 | Room + 音频文件；模型安装校验大小与 SHA-256 |

“降级成功”只表示仍有产物可用。抽取摘要不等价于生成摘要，转写可用也不等于摘要已完成。模型限制、两端行为和代码定位见[技术方案](docs/technical-design.md)。

## 产品与技术决策

| 决策 | 为什么 | 需要承担的代价 |
| --- | --- | --- |
| 核心音频与推理留在本机 | 减少上传与网络依赖，让私密记录也能整理 | 安装体积、内存、耗电与兼容性成为产品成本 |
| 保留转写、时间戳和原音频 | 摘要会遗漏或误解，用户需要核验入口 | 当前没有逐句摘要引用，核验仍需用户操作 |
| 摘要失败不抹掉转写 | 一次生成失败不应让整段工作归零 | 必须区分生成、抽取和不可用，避免误导性“成功” |
| 买断后本地处理 | 公开商店定位为一次购买、无按分钟转写费 | 持续模型适配与支持仍有成本，不能称为零成本 AI |

产品判断、替代方案与发布门槛见[产品决策](docs/case-study.md)；具体模型、上下文、恢复、导出和语言设置见[技术方案](docs/technical-design.md)。

## 如何判断产品是否有价值

目前能确认早期下载与收益，尚不能确认持续使用。下一轮以**每周完成有效笔记任务的活跃设备数**为核心使用指标：转写保存后发生回听、编辑或导出是行为代理；正确性由固定音频集与授权研究另行核验。DAU / MAU、激活和留存使用明确分母，不拿下载量代替。

1. **先解决首次任务：**观察导入、等待、查找与导出的真实卡点。
2. **再验证 AI 增益：**比较纯回听、转写、转写 + 摘要，先看找到的信息是否正确，再看时间。
3. **最后决定扩量：**按来源和地区观察商店获取，同时检查兼容反馈、退款与使用质量。

[经营快照、指标定义和实验方案](docs/metrics-and-experiments.md)包含当前数据、待测指标、最小事件合同与决策规则。
