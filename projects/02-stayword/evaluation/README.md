## 下一轮固定音频测试集：先质量，再速度

下表是**设计好的验收卡，尚未执行，不是成绩表**。优先每类 2 条、共 12 条固定音频作为最小诊断集；数量是规划值，不宣称统计代表性。每条建立人工逐字稿及关键事实清单，获得使用许可后才能进入演示材料。

| 样本 | 主要风险 | 核对方式 |
| --- | --- | --- |
| 清晰中文短录音 | 数字、日期、否定词 | CER + 关键事实逐项核对 |
| 清晰英文短录音 | 人名、缩写、口音 | WER + 专名清单 |
| 多人交替讲话 | 说话人及行动归属 | 原音频对照；双端分别记录，不假设都支持分离 |
| 噪声 / 静音 / 无语音 | 幻觉式转写、空输入、永久等待 | 是否明确终止、原音频是否保留 |
| 长录音与跨段修正 | 前段决定被后段否定，整合遗漏 | 检查跨段关键事实与结论是否正确更新 |
| 文件导入与编码变化 | 解码失败、时长错误、位置不同步 | 核验时长、关键时间点回听与错误提示 |

CER = 字符编辑距离 / 参考字符数；WER 使用参考词数。规范化规则需在测量前冻结。摘要关键事实覆盖 = 正确保留的标注事实 / 必需事实；无依据断言率 = 无来源断言数 / 摘要断言数。分母为零时记 N/A，不记 0% 错误。至少人工复核数字、专名、归属与不确定性。

速度记录音频时长、冷 / 热启动、转写时间、摘要时间和总完成时间，报告每条原始结果与设备、系统、应用版本、模型。实时因子 RTF = 处理耗时 / 音频时长；只测转写就明确写 ASR RTF，不能暗示包括摘要与导入。12 条诊断集不足以稳定估计尾部延迟，暂不包装 P95 服务承诺。
