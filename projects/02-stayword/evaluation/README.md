# StayWord 验证方案

状态：待执行，未填写真机成绩。

## 首轮范围

先选择一个端和一台实际可用设备，记录型号、系统、应用提交、模型版本与测试时间。建议覆盖短清晰中文、英文、多人、噪声、长录音及文件导入等 6 类样本；语言与时长应按真实需求调整。

样本须允许用于演示，涉及他人声音的文件不默认公开。

## 测量

- 转写：使用人工核对的参考文本；中文可记录字符错误率，英文可记录词错误率，说明规范化规则和分母。
- 摘要：关键事实覆盖、无依据断言、人物/数字错误，由人工核对；不以模型自评分代替。
- 性能：冷启动/热启动分开，记录音频时长、处理时间、设备与模型。
- 体验：可理解的等待状态、错误提示、重试入口以及原音频是否保留。
- 恢复：后台、应用终止、取消、存储不足等情形逐项测试，记录是否丢失或重复结果。

## 边界测试

首次授权拒绝、取消导入、无有效语音、长录音、播放中断、处理过程中删除任务、模型缺失/初始化失败。两端能力不同，分别确认预期，不机械要求行为相同。

results-template.csv 仅为记录模板。没有进行的测试留空，不将零值当作成功。
