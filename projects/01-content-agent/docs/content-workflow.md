# content-workflow：把视频理解转成可独立阅读的图文

我用 content-workflow 将值得解释的 YouTube 视频改编为中文图文。重点是保留原内容依据，让正文和卡片分别适合阅读，并允许在生成前后调整结构。

[整体产品设计](case-study.md) · [实际输入与图文产物](../demo/content-workflow/2026-08-27-literature-review/README.md) · [技术实现](architecture.md)

## 1. 使用场景与问题定义

输入通常是一条值得解释的外部视频。最终读者需要的是一篇可以直接理解的中文内容，可能只读正文，也可能只滑动图片，并不一定先看原视频。

从任务拆解看，人工完成这件事需要依次理解内容、整理依据、选择角度、写正文、规划卡片与检查成图。容易发生三类问题：理解材料散落在对话中，修改时重复解释；正文与图片各自生成后，事实或重点不一致；图片只是正文的缩略版，缺少独立阅读所需的解释。这些是设计针对的任务风险。个人实际生产总结中的旧方案效率对比见[生产结果](../README.md#个人贡献与生产结果)；本页历史案例未单独记录完整配对计时。

真实记录提供了更具体的需求：2026-08-27 的“分析 YouTube 视频内容”任务中，用户要求把八张图改成六张，调整风格，并增加内页解释，使读者只看图片也能理解内容。另一次正文修改要求把 Agent 记忆主题转成 AI 产品经理视角。它们说明卡片密度、目标读者和表达角度都需要可调整，不能固定为一次性摘要。

## 2. 产品目标与完成条件

目标是形成“可回查的分析 + 可独立阅读的正文／卡片”，减少理解材料的重复传递，并让人工修改集中在表达与判断上。总体效率采用个人生产总结口径；逐任务的人工修改与模型等待仍需分开记录。

| 优先级 | 要解决的事 | 首版验收条件 |
| --- | --- | --- |
| 必须 | 内容有依据 | 主要论点、数字与限定可回查分析及原始内容；时间戳有用 |
| 必须 | 阅读方式成立 | 正文可独立阅读；卡片按顺序阅读也能理解核心观点 |
| 必须 | 分支可修改 | 正文和卡片使用同一分析；改卡片数量或风格时不必重做无关产物 |
| 必须 | 获取失败可处理 | 说明字幕来源；无字幕时明确转写条件及确认状态 |
| 后续验证 | 修改负担可控 | 记录人工修正事实、文案和图片的时间、次数与原因 |

首版不包含视频画面理解、视频剪辑或平台发布。字幕路径不能支撑只在画面中出现的信息；此类素材需要补充依据或限定结论。

## 3. 输入、交付与过程

输入为视频 URL、目标读者／表达要求与任务目录。交付范围可以是分析、正文、卡片或整套图文，开始时明确。

```text
视频 URL → 按语言选字幕轨道（候选语言内人工优先）
                       └─ 无字幕 → 告知条件并确认 → Whisper 转写
内容 → analysis.md
          ├─ note-writer → result/post.md
          └─ note-images → plan.md → 确认 → prompts/ → result/图片
```

字幕工具处理获取、转写与文件；Agent 完成分析、改编和视觉创作；用户确定角度、确认图片规划并验收成品。analysis.md 保留完整理解和依据；两类发布产物各自选择表达顺序，不能引入无依据的事实。

图片计划应明确页数、每页核心意思、信息密度和风格。修改计划后再生成，可以提前处理六张还是八张、简洁还是解释充分等需求。现有 Skill 允许本次请求明确免确认；这不等于取消最终质量检查。

## 4. 方案选择与代价

| 设计问题 | 当前方案 | 可比较方案与代价 |
| --- | --- | --- |
| 如何复用理解 | 将 analysis.md 作为两个分支的共同输入 | 从视频分别生成正文和图，会重复理解；共享分析则需维护分析质量及两分支一致性 |
| 如何组织图片 | 图片直接依据分析单独规划 | 从完成的正文机械拆卡更直接，但正文结构不一定适合独立滑读；独立规划增加一次内容检查 |
| 如何控制获取成本 | 字幕优先，无字幕才确认转写 | 默认转写路径更统一，但所有任务都承担音频处理；当前方案需处理字幕质量差异 |
| 如何控制返工 | 出图前可检查计划，完成后逐张验收 | 一次出图操作少，但结构不合适时可能整套返工；计划确认会增加交接 |

八张改六张的记录可以解释计划调整的实际用途，不能据此声称已经测得返工成本下降。

## 5. 异常与质量边界

字幕获取失败时保留错误与已尝试方式；未获准转写时停在该环节。自动字幕可能漏词，分析需保留不确定项。中文正文检查事实、受众和表达；图片检查文字、顺序、规格与独立阅读。单个分支失败时记录部分交付，不把另一分支的成功当成整套成功。
