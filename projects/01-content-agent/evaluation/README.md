## 样本与比较

先以 6 个冒烟任务确认链路可运行：字幕正常、字幕不可用、长素材、明确脚本、规格异常、生成结果需修改。正式小样本对比建议 20—30 个固定任务，覆盖两条工作流并说明各类样本数；少量重复运行观察波动，不宣称统计显著。

如果对比 Browser Agent、手动流程和 Skill 方案，固定输入、交付要求与人工验收标准，记录日期、模型和工具版本。无历史基线时先采集当前基线，不反推百分比。

## 记录口径

- 完成率：通过事先约定的内容与格式验收的任务／全部任务。
- 人工成本：主动操作分钟数、修改轮数；与模型等待时间分开。
- 延时：开始到验收的端到端时间，展示样本数、中位数和范围。
- 成本：包含失败重试、图片和转写；Token 数量不能直接等同费用。
- 单个合格结果成本：全部测试支出／合格结果数量。
- 质量：事实、来源、可编辑性、规格与人工采纳；模型评分仅作辅助。

每次运行填写下方 CSV 模板；空字段表示未测，禁止填虚构的 0。费用币种单列，未计本地算力成本时说明。

## 失败分类

输入不可读、获取失败、权限/依赖问题、模型请求失败、事实不符、格式错误、图片文字错误、人工放弃。成功案例与失败案例都保留输入与输出；私有样本公开前另行替换。
