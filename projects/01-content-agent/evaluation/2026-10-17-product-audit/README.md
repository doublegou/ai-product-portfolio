2026-10-17。评测包含三种数据：**重新统计的历史运行、新执行的本地规则测试、新执行的联网采集**。费用敏感性分析另列为估算。生产模型没有重新调用，没有发送邮件或发布内容。

## 1. 运行成功为什么不等于任务有效

统计范围为仓库内 2026-07-09、07-10、07-11 三份原始日志，共 189 个事件。按 run_id 分组：13 个运行有起始事件，其中三个为 daily，十个为 strategy_collect。另有 26 个没有起始事件的运行片段，保留在 results.json，但不纳入完整运行的分母。

十次策略采集全部记录 success。九次有明确结果汇总：六次没有创作者或笔记；一次有创作者、没有笔记；两次各有一条笔记。另一次缺少汇总，不能补成成功取得素材。这里的策略采集属于 **content-agent 的研究模块**，不是 daily-trend-radar。

**决策影响：** 产品完成条件应增加“取得符合任务要求的研究素材”，并将空结果、缺少结果汇总、完整结果分别呈现。现有程序状态字段尚未因此全部重构，这一发现列入后续优先项。

## 2. 一条草稿的生成投入

运行 `20260709-131559-330e67`：13:15:59 开始，13:19:43 第二轮审稿通过并保存，13:20:00 发布准备失败。以下仅对应这一条运行，按日志统计。

| 阶段 | 调用次数 | 已记录输入 Token | 已记录输出 Token | 调用耗时合计 |
| --- | ---: | ---: | ---: | ---: |
| 选题规划 | 1 | 31,440 | 1,291 | 14.743 秒 |
| 研究分析 | 1 | 12,412 | 2,948 | 39.530 秒 |
| 初稿 | 1 | 11,021 | 1,268 | 13.410 秒 |
| 模型审稿 | 2 | 23,253 | 5,961 | 57.678 秒 |
| 改稿 | 1 | 11,698 | 1,014 | 14.177 秒 |
| **合计** | **6** | **89,824** | **12,482** | **139.538 秒** |

整次运行 241.341 秒还包含采集、程序执行与发布准备；不能把全部时间归因于模型。调用耗时按日志相加，不用于推算多人并发吞吐。本次 Token 覆盖 6/6 次调用；数据来自当时服务返回的 usage，不是独立账单。

另一次 `20260709-130817-2f8f86` 运行 378.816 秒，10 次调用，其中 9 次有 Token 数据，已知合计 121,611；五轮审改仍未通过。它不能与前一条合成一次成功任务，也不能把缺失用量填成零。

**优化判断：** 该成功保存样本中输入占约 87.8% 的 Token。应先检查重复携带的上下文是否必要，再对比减少输入后事实质量是否下降；尚无裁剪实验，不能承诺同等质量下降本比例的费用。与其延长审改上限，更应定位资料缺口、错误类型和采集是否有效。

## 3. 费用敏感性分析（假设，不是实测账单）

用上述完整记录的用量计算：

`单次 LLM 费用 = 0.089824 × 输入单价 + 0.012482 × 输出单价`

单价单位为元 / 百万 Token。下表三个价格场景是为了看预算敏感性而设定，**不是任何厂商的实际报价**，没有据此宣称节省金额。

| 假设输入 / 输出单价 | 该次调用估算费用 |
| --- | ---: |
| 1 / 4 元每百万 Token | 约 ¥0.14 |
| 5 / 20 元每百万 Token | 约 ¥0.70 |
| 10 / 40 元每百万 Token | 约 ¥1.40 |

这是一次记录完整的 LLM 运行费用情景，未含图片、采集操作、人工复核和此前失败任务。最终应将全部可归属支出除以实际合格交付数；当前没有人工采纳与账单，不能计算真实“每篇可发布内容成本”或 ROI。

## 4. 规则边界测试：看漏报与误报

样本为本轮根据产品资料构造，特意覆盖明确风险、同义表达和否定句；由当前助手定义期望，未经过独立人工标注。测试直接执行 `find_quality_guard_issues`，不调用模型 reviewer；因此 **6/12 不是模型准确率，也不是线上错误率**。

| 样本组 | 期望 | 当前结果 |
| --- | --- | --- |
| 明确“完全离线”“一定能看到”等风险，3 条 | 提示风险 | 3 条均提示 |
| 未支持的自动识别、荣誉映射、断网全部可用，3 条 | 提示风险 | 3 条均漏报 |
| 产品资料支持的正常功能表达，3 条 | 不提示风险 | 3 条均不提示 |
| 否定效果保证或否定本地承诺，3 条 | 不因该表达阻断 | 3 条均误报 |

例如，“用热点地图一定能看到鸟”应被拦截；“热点地图不保证看到鸟”是合理边界说明，却也被当前词表命中。相反，“断网也能使用全部功能”避开了现有关键词，但同样缺少资料支持。

**验收调整：** 对事实不应只给总分。先标记具体主张，再核对支持资料、否定关系及功能范围；缺少支持的主张进入人工复核。这里是基于测试得出的改进方向，未宣称已实现完整的语义事实校验器。
