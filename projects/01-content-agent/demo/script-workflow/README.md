# script-workflow：口播配套素材

这里保留两类实际任务：已有实机演示时只做文案与封面；同一期口播稿制作整套配套素材，并在版本变化后修订演示。

| 任务 | 阅读入口 | 重点 |
| --- | --- | --- |
| 第 004 期：部分执行 | [真实需求与修改反馈](2026-09-25-partial-task/README.md) | 跳过已有演示，手动改文案，再修改封面 |
| 第 005 期：原始素材 | [原稿、文案与三封面](2026-09-26-agentic-video/README.md) | 演示和 post 独立编号；素材之间的主题关系 |
| 第 005 期：当前修订 | [对齐记录与截图](2026-10-16-version-alignment/README.md) | 按修订稿调整第 5–7 页，检查播放与关联版本 |

先看修订记录，再按需要回查历史原件。HTML 克隆后可本地播放；GitHub 上可直接查看截图与成图。文件规格与内容一致性已经核对，人工最终采纳未据此推定。
