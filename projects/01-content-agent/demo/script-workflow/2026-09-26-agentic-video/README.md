## 实际使用：播放、反馈、继续制作

这次任务先做演示。用户打开产物后反馈“样式没错，功能也没错，但是没居中”，又要求某句话和上一步一起出现。之后确认 PPT 与视频制作完成，再进入发布素材。封面阶段，用户已经手动修改文案，继续指出人像清晰度、油光和设计感问题。

| 用户动作 | 已发生的处理 | 产品意义 |
| --- | --- | --- |
| 打开并播放演示 | 修正控制栏居中与分步出现时机 | 交互验收要覆盖实际讲述，不止静态页面 |
| 提交修订后的本期原稿 | 继续生成文案与封面 | 同一期内容可能在制作中更新 |
| 手动修改文案 | 保留用户已改内容，再调整封面 | 人工编辑成为后续输入 |
| 反馈封面视觉 | 更新三种画幅 | 比例合格只是基础；人像和视觉层级另行判断 |

以上可在[原始对话](conversation-excerpts.json)逐项回查。封面旧版本没有完整保存，不能制作“视觉提升前后对比”或宣称改善比例。可核实的版本对照是原稿与演示，第 5–7 页的变化见[修订记录](../2026-10-16-version-alignment/README.md)。
