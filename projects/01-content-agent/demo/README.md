# 四类任务的实际交付

[返回项目](../README.md) · [产品设计与需求规划](../docs/case-study.md)

这四个案例覆盖资料改编、口播配套、产品内容和选题研究。每个案例都把输入、过程中的判断与最终产物放在一起，便于查看一次任务究竟交付了什么。

| 用户任务 | 实际交付 | 关键判断 |
| --- | --- | --- |
| [把一条视频改编为中文图文](content-workflow/2026-08-27-literature-review/README.md) | 分析、正文、两版图片规划与六张生成原图 | 从八张调整为六张时重新组织解释顺序，保留图片独立阅读能力 |
| [为一期口播准备完整发布素材](script-workflow/2026-09-26-agentic-video/README.md) | 原稿、15 页演示、发布文案与三比例封面 | 发现演示与修订稿不一致后修订相关页面，固定六份交接文件 |
| [生成可核查的产品草稿](content-agent/2026-10-16-draft-review/README.md) | 历史草稿、逐项主张核查与修订候选 | 模型审稿通过后继续核查事实；草稿保存与发布准备分别判断 |
| [从榜单中形成可继续研究的选题](daily-trend-radar/2026-10-16-source-check/README.md) | 三源 15 条记录、来源报告与三个候选简报 | 区分抓取时间与发布时间，对缺失信息和部分失败保留状态 |

图文案例保留生成原图，最终裁切文件未归档；口播案例同时保留历史演示与修订版；产品草稿的修订经过 AI 辅助审校，尚不代表人工采纳；雷达结果来自一次真实采集。各页说明对应的检查范围，完整运行方法见 [Quick start](../docs/quick-start.md)。
