# 演示准备

状态：脚本已设计，尚未录制或完成本轮运行验收。

## 主演示约 90 秒

- 0—15 秒：展示真实输入和预期交付，不先介绍技术栈。
- 15—45 秒：展示字幕获取、分析及生成过程，标注加速播放。
- 45—65 秒：展示最终正文和图片，指出人工检查了什么。
- 65—90 秒：展示一条独立的失败样例及恢复过程，交代实际耗时和适用边界。

## 第二条工作流

选择本人允许展示的脚本，展示 HTML 演示、post.txt 和三个比例封面。保留输入与产物对应关系，避免将不同任务的最佳结果拼成一次运行。

未来实际产物放在本目录的 samples/ 中，录屏放 recordings/；当前不创建假样例。运行 content-agent 时关闭实际发布，不触发第三方账号写入。
