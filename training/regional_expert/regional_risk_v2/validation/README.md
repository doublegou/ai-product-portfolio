# Regional Risk V2 validation evidence

The files at this directory root are the versioned aggregate evidence for the frozen V2 result. They include all Outer OOF predictions, Gate and ranking metrics, branch/extreme audits, selected Inner thresholds, fit diagnostics, variable importance and the OOF manifest.

The 68 task directories and Slurm run logs are retained in the checksum-verified archive `regional_risk_v2_regional_risk_v2_20260817_r1.tar.gz` rather than duplicated in Git.
