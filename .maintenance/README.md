`sources.json` 内的工程路径与各项目机器可读记录仍以仓库根目录为基准。维护文件移位不改变原始代码、许可、模型、运行结果或归档身份；计划与审查文件中的旧目录描述按历史时点阅读。

历史展示检查 JSON 中的文件路径与指纹对应当时版本，仅作维护记录，不表示当前页面已按相同条件重新验收。
